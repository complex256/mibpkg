# Installing mibpkg

The install guide moved to the documentation site:

- **[Install mibpkg](https://complex256.github.io/mibpkg/getting-started/install/)** — engineering-menu method
- **[Custom-script install](https://complex256.github.io/mibpkg/getting-started/install-custom-script/)** — the alternative method
- **[First use](https://complex256.github.io/mibpkg/getting-started/first-use/)** — the web interface

The short version: unzip `mibpkg-sd-<version>.zip` onto a FAT32 SD card partitioned with Master Boot
Record, insert it in SD1, and run the engineering menu's software update.
