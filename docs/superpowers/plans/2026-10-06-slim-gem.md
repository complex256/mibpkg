# Slim GEM (web interface M2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** GEM shows one mibpkg page — web server status and address, listen mode and PIN (read-only),
and three recovery buttons — and nothing else; packages, logs and sources are web-only.

**Architecture:** `gem::screens` returns a single `Screen` (`mibpkg`, under `settings.gem_parent`).
`gem::regenerate` already deletes every mibpkg `.esd` and button script it no longer wants, so
upgrading a unit from 0.4.x removes the per-package screens and `mibpkg__web` by itself. The `gem`
CLI verbs stay (the web UI runs them); only the generated screens shrink.

**Tech Stack:** Rust 2021 (std + existing deps). No front-end changes.

**Spec:** `docs/superpowers/specs/2026-10-05-web-interface-design.md` (section "GEM", M2).

## Global Constraints

- The page (spec M2): web server status and URLs; listen mode and PIN set (read-only); buttons
  Restart web server (`web-restart`), Reset web settings (`web-reset`), Update mibpkg.
- "Update mibpkg" runs `gem install mibpkg` (newest mibpkg on the card or online; the card wins a
  tie). The button is always shown: GEM screens are regenerated only after actions, not on card insert.
- Live rows (GEM re-reads them while open): supervisor (`KEY_SUPERVISOR`), web server
  (`service_key("mibpkg.web")`), last result (`KEY_RESULT_GLOBAL`, when present), last mibpkg update
  result (`result_key("mibpkg")`, when present).
- No new crate dependencies. Version 0.5.0.
- Do not rewrite an unchanged `.esd` (an open GEM screen stops polling when its file changes) —
  `regenerate` already guarantees this; keep its test.

## Review Focus

- A unit upgraded from 0.4.x has `mibpkg_<pkg>.esd`, `mibpkg__web.esd` and their button scripts:
  all must be gone after the first action under 0.5.0, and `mibpkg.esd` must remain → Task 1 test
  `upgrading_removes_the_package_and_web_screens`.
- The web server is broken and the user only has GEM: the page must still offer Restart, Reset and
  Update, whatever web.toml says (disabled, unreadable) → Task 1 test
  `recovery_buttons_are_always_there`.
- web.toml unreadable: the page shows the warning text, not an error, and still renders → Task 1.
- No web.url yet (server not started / interfaces down): "address: not known yet" line → Task 1.
- DISABLE card present: the page says so (no services start, web included) → Task 1.

```rust
pub struct Model<'a> {
    pub layout: &'a Layout,
    pub unit: &'a UnitInfo,
    /// DISABLE marker on a card: no services start (the web server neither).
    pub disabled: bool,
    /// A global result exists (restart / reset web): show its live row.
    pub has_result: bool,
    /// A result for mibpkg itself exists (Update mibpkg): show its live row.
    pub has_update_result: bool,
}

/// The one GEM page (web interface M2): where the web interface is, how it is set up, and the
/// buttons that still work when it does not. Packages, logs and sources live in the web UI.
pub fn screens(m: &Model) -> Vec<Screen> {
    let (web, warning) = crate::web::settings::load(m.layout);
    let mut items = vec![
        text(format!("mibpkg {} - unit {}", env!("CARGO_PKG_VERSION"), m.unit.describe())),
        Item::Live { label: "supervisor".into(), key: crate::persist::KEY_SUPERVISOR },
    ];
    if m.disabled {
        items.push(text("DISABLE marker on the card: no services are started (the web server neither)"));
    }
    items.push(Item::Live { label: "web server".into(), key: crate::persist::service_key(crate::cli::WEB_SERVICE) });
    if !web.enabled {
        items.push(text("web server disabled in web.toml (Reset web settings turns it back on)"));
    }
    // Written by the running server: "port N", "<class> <url>" lines, "iface <name> <addr>" lines.
    let file = fs::read_to_string(m.layout.run("web.url")).unwrap_or_default();
    let lines: Vec<&str> = file.lines().skip(1).collect();
    let ifaces: Vec<&str> = lines.iter().filter_map(|l| l.strip_prefix("iface ")).collect();
    let urls: Vec<String> = lines.iter().filter(|l| !l.starts_with("iface ")).map(|l| l.replacen(' ', ": ", 1)).collect();
    if urls.is_empty() && ifaces.is_empty() {
        items.push(text("address: not known yet (join the car's Wi-Fi, then open this screen again)"));
    } else if urls.is_empty() {
        items.push(text("address: no hotspot or Tailscale address recognised (see interfaces below)"));
    }
    for u in urls {
        items.push(text(u));
    }
    if !ifaces.is_empty() {
        items.push(text(format!("interfaces up: {}", ifaces.join(", "))));
    }
    items.push(text("Packages, logs and settings: open the address above in a phone browser"));
    items.push(text(format!("listen: {}", web.listen.join(", "))));
    items.push(text(format!("PIN: {}", if web.pin.is_some() { "set" } else { "not set" })));
    if let Some(w) = warning {
        items.push(text(w));
    }
    items.push(button("Restart web server", &["web-restart"]));
    items.push(button("Reset web settings", &["web-reset"]));
    items.push(button("Update mibpkg (SD card or online)", &["install", SELF]));
    if m.has_result {
        items.push(Item::Live { label: "last result".into(), key: crate::persist::KEY_RESULT_GLOBAL });
    }
    if m.has_update_result {
        items.push(Item::Live { label: "mibpkg update".into(), key: crate::persist::result_key(SELF) });
    }
    vec![Screen { name: "mibpkg".into(), parent: m.layout.settings.gem_parent.clone(), items }]
}
```
