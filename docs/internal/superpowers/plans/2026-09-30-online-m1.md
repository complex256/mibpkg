# Online Updates — Milestone 1 (time + fetch) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A car with internet finds newer versions in the official online collection ("Check for updates" in GEM, plus a background check) and installs them from the internet on a tap; the three feasibility gates are answered first.

**Architecture:** `clock` gets a network-time offset from its own SNTP query (never from other packages' files: Tailscale is optional); `fetch` downloads over HTTPS through the unit's own libcurl (dlopen, hand-written FFI, OpenSSL verify time = now + offset, our CA bundle); `online` resolves sources, fetches and caches index.json per collection, and exposes cached online collections next to SD ones; `install` downloads remote packages to /tmp before the unchanged install path; the supervisor spawns `mibpkg online-check` when `internet` holds; GEM gets a Check-for-updates button, a live `online` row and `online [id]: <version>` lines. Signatures/trust (M2), sources/list (M3) and publisher tooling (M4) come in later plans.

**Tech Stack:** Rust (std-only, as before), libcurl 7.56 + OpenSSL 1.0.2j on the unit via dlopen; host tests use macOS `/usr/lib/libcurl.4.dylib`.

**Spec:** `docs/superpowers/specs/2026-09-30-online-updates-design.md`

## Global Constraints

- Std-only pure-Rust deps in mibpkg; no new crates in this plan (the ed25519 spike is throwaway, under `spikes/`).
- HTTPS only for online sources and package URLs (`http://` refused) — tests may enable plain HTTP via `CurlFetcher.allow_http`.
- Limits: 30 s per request; index ≤ 1 MB; package ≤ 50 MB. Downloads go to `/tmp` (flat names `mibpkg.dl.<name>-<version>.mpk`), deleted after use.
- The system clock is never changed; the offset is only used for TLS verification.
- Nothing is installed without a user action; background checks only fetch index.json.
- Default official source: `github:complex256/mibpkg-packages` (Settings `online_sources`).
- Flash writes only when content changes (online cache files, GEM files, persistence values).
- Git author complex256 <me@complex256.dev>; trailer `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`; never reference the owner's real name.
- Creating the public GitHub repo / release for the official collection is an outward action: ask the user first (Task 9).

## Review Focus

1. **Network fails mid-check (DNS, timeout, HTTP 404)** — the error is reported, the previous cache stays usable, nothing else changes (test in Task 5).
2. **Malformed or oversized index from the network** — refused, cache unchanged (test in Task 5).
3. **A package URL in an online index that is `http://` or another scheme** — refused when the collection loads (test in Task 5).
4. **Same collection id on the SD card and online with different versions** — newest compatible version is chosen; with no cache (offline) the SD copy still works (test in Task 5).
5. **Download interrupted or corrupted** — the /tmp download is removed and nothing is installed (test in Task 6).

```rust
//! Network time for TLS certificate checks. The unit's clock reads 1970 (nothing sets it), so
//! mibpkg keeps an offset (network - local seconds) and applies it only to certificate checks.
use crate::fsutil::atomic_write;
use crate::paths::Layout;
use crate::status::now_secs;
use anyhow::{bail, Context, Result};
use std::net::UdpSocket;
use std::time::Duration;

/// Seconds from 1900-01-01 (NTP epoch) to 1970-01-01.
pub const NTP_UNIX_DELTA: u64 = 2_208_988_800;
pub const SERVERS: &[&str] = &["time.cloudflare.com:123", "pool.ntp.org:123"];

/// One SNTP (RFC 4330) query: returns network time minus local time, in seconds.
pub fn sntp_offset(server: &str, timeout: Duration) -> Result<i64> {
    let sock = UdpSocket::bind("0.0.0.0:0").context("udp bind")?;
    sock.set_read_timeout(Some(timeout))?;
    sock.connect(server).with_context(|| format!("sntp {server}"))?;
    let mut req = [0u8; 48];
    req[0] = 0x23; // LI 0, VN 4, mode 3 (client)
    sock.send(&req).with_context(|| format!("sntp {server}"))?;
    let mut resp = [0u8; 48];
    let n = sock.recv(&mut resp).with_context(|| format!("sntp {server}: no answer"))?;
    if n < 48 {
        bail!("sntp {server}: short answer");
    }
    let secs = u32::from_be_bytes([resp[40], resp[41], resp[42], resp[43]]) as u64;
    if secs <= NTP_UNIX_DELTA {
        bail!("sntp {server}: invalid time");
    }
    Ok((secs - NTP_UNIX_DELTA) as i64 - now_secs() as i64)
}

fn read_i64(p: &std::path::Path) -> Option<i64> {
    std::fs::read_to_string(p).ok()?.trim().parse().ok()
}

/// The offset this mibpkg measured earlier this boot (never another package's file).
pub fn read_offset(layout: &Layout) -> Option<i64> {
    read_i64(&layout.run("clock_offset"))
}

/// The offset, querying `servers` in order (and caching the answer) when none is known yet.
pub fn ensure_offset(layout: &Layout, servers: &[&str], timeout: Duration) -> Result<i64> {
    if let Some(o) = read_offset(layout) {
        return Ok(o);
    }
    let mut last = None;
    for s in servers {
        match sntp_offset(s, timeout) {
            Ok(o) => {
                atomic_write(&layout.run("clock_offset"), o.to_string().as_bytes())?;
                return Ok(o);
            }
            Err(e) => last = Some(e),
        }
    }
    Err(last.unwrap_or_else(|| anyhow::anyhow!("no time servers configured")))
}
```

```rust
//! HTTPS downloads through the unit's own libcurl (7.56 + OpenSSL 1.0.2j), loaded with dlopen:
//! no Rust TLS stack builds for QNX 6.5 (spikes/README.md). Certificates are checked against our
//! CA bundle at network time (the unit clock is 1970) via CURLOPT_SSL_CTX_FUNCTION.
use crate::paths::Layout;
use anyhow::{bail, Result};
use std::cell::RefCell;
use std::collections::HashMap;
use std::ffi::{c_char, c_int, c_long, c_void, CStr, CString};
use std::path::PathBuf;
use std::sync::atomic::{AtomicI64, Ordering};
use std::sync::OnceLock;

pub const MAX_INDEX: u64 = 1 << 20;
pub const MAX_PACKAGE: u64 = 50 << 20;

pub trait Fetcher {
    fn get(&self, url: &str, max_bytes: u64) -> Result<Vec<u8>>;
}

/// No network access in this context (host tests, or a command that never fetches).
pub struct Unavailable;
impl Fetcher for Unavailable {
    fn get(&self, url: &str, _max: u64) -> Result<Vec<u8>> {
        bail!("online fetching is not available here ({url})")
    }
}

/// Test double: URL -> body; records every request.
#[derive(Default)]
pub struct MemoryFetcher {
    pub files: RefCell<HashMap<String, Vec<u8>>>,
    pub calls: RefCell<Vec<String>>,
}
impl Fetcher for MemoryFetcher {
    fn get(&self, url: &str, max: u64) -> Result<Vec<u8>> {
        self.calls.borrow_mut().push(url.to_string());
        match self.files.borrow().get(url) {
            Some(b) if b.len() as u64 > max => bail!("{url}: larger than {max} bytes"),
            Some(b) => Ok(b.clone()),
            None => bail!("{url}: HTTP 404"),
        }
    }
}

extern "C" {
    fn dlopen(file: *const c_char, mode: c_int) -> *mut c_void;
    fn dlsym(handle: *mut c_void, name: *const c_char) -> *mut c_void;
    fn dlerror() -> *const c_char;
    fn time(t: *mut TimeT) -> TimeT;
}
#[cfg(target_os = "nto")]
type TimeT = i32; // QNX 6.5 time_t is 32-bit
#[cfg(not(target_os = "nto"))]
type TimeT = i64;
const RTLD_NOW: c_int = 0x0002;
#[cfg(target_os = "nto")]
const RTLD_GLOBAL: c_int = 0x0100;
#[cfg(not(target_os = "nto"))]
const RTLD_GLOBAL: c_int = 0x0008;

const CURLOPT_URL: c_int = 10002;
const CURLOPT_CAINFO: c_int = 10065;
const CURLOPT_FOLLOWLOCATION: c_int = 52;
const CURLOPT_WRITEFUNCTION: c_int = 20011;
const CURLOPT_WRITEDATA: c_int = 10001;
const CURLOPT_ERRORBUFFER: c_int = 10010;
const CURLOPT_USERAGENT: c_int = 10018;
const CURLOPT_TIMEOUT: c_int = 13;
const CURLOPT_NOSIGNAL: c_int = 99;
const CURLOPT_SSL_CTX_FUNCTION: c_int = 20108;
const CURLINFO_RESPONSE_CODE: c_int = 0x200002;

struct Api {
    init: unsafe extern "C" fn() -> *mut c_void,
    setopt: unsafe extern "C" fn(*mut c_void, c_int, ...) -> c_int,
    perform: unsafe extern "C" fn(*mut c_void) -> c_int,
    getinfo: unsafe extern "C" fn(*mut c_void, c_int, ...) -> c_int,
    cleanup: unsafe extern "C" fn(*mut c_void),
    get0_param: Option<unsafe extern "C" fn(*mut c_void) -> *mut c_void>,
    set_time: Option<unsafe extern "C" fn(*mut c_void, TimeT)>,
}

static API: OnceLock<std::result::Result<Api, String>> = OnceLock::new();
static VERIFY_TIME: AtomicI64 = AtomicI64::new(0);

unsafe fn open(path: &str, global: bool) -> std::result::Result<*mut c_void, String> {
    let c = CString::new(path).unwrap();
    let h = dlopen(c.as_ptr(), RTLD_NOW | if global { RTLD_GLOBAL } else { 0 });
    if h.is_null() {
        let e = dlerror();
        return Err(if e.is_null() { format!("dlopen {path}") } else { CStr::from_ptr(e).to_string_lossy().into() });
    }
    Ok(h)
}

unsafe fn sym<T: Copy>(h: *mut c_void, name: &str) -> std::result::Result<T, String> {
    let c = CString::new(name).unwrap();
    let p = dlsym(h, c.as_ptr());
    if p.is_null() {
        return Err(format!("missing symbol {name}"));
    }
    Ok(std::mem::transmute_copy(&p))
}

fn load(lib: &str, preload: &[String]) -> std::result::Result<Api, String> {
    unsafe {
        let mut ssl = None;
        let mut crypto = None;
        for p in preload {
            let h = open(p, true)?;
            if p.contains("libssl") {
                ssl = Some(h);
            }
            if p.contains("libcrypto") {
                crypto = Some(h);
            }
        }
        let h = open(lib, false)?;
        Ok(Api {
            init: sym(h, "curl_easy_init")?,
            setopt: sym(h, "curl_easy_setopt")?,
            perform: sym(h, "curl_easy_perform")?,
            getinfo: sym(h, "curl_easy_getinfo")?,
            cleanup: sym(h, "curl_easy_cleanup")?,
            get0_param: match ssl { Some(s) => sym(s, "SSL_CTX_get0_param").ok(), None => None },
            set_time: match crypto { Some(c) => sym(c, "X509_VERIFY_PARAM_set_time").ok(), None => None },
        })
    }
}

struct Sink {
    buf: Vec<u8>,
    max: u64,
    over: bool,
}

extern "C" fn write_cb(ptr: *const u8, size: usize, n: usize, ud: *mut c_void) -> usize {
    let sink = unsafe { &mut *(ud as *mut Sink) };
    let len = size * n;
    if sink.buf.len() as u64 + len as u64 > sink.max {
        sink.over = true;
        return 0; // makes curl abort the transfer
    }
    sink.buf.extend_from_slice(unsafe { std::slice::from_raw_parts(ptr, len) });
    len
}

/// Sets OpenSSL's verification time to network time (the unit clock is 1970).
extern "C" fn ssl_ctx_cb(_curl: *mut c_void, ssl_ctx: *mut c_void, _p: *mut c_void) -> c_int {
    if let Some(Ok(api)) = API.get() {
        if let (Some(get0), Some(set)) = (api.get0_param, api.set_time) {
            unsafe {
                let param = get0(ssl_ctx);
                if !param.is_null() {
                    set(param, VERIFY_TIME.load(Ordering::Relaxed) as TimeT);
                }
            }
        }
    }
    0
}

                bail!("curl_easy_init failed");

            (api.setopt)(c, CURLOPT_NOSIGNAL, 1 as c_long);
            (api.setopt)(c, CURLOPT_ERRORBUFFER, err.as_mut_ptr());
            (api.setopt)(c, CURLOPT_WRITEFUNCTION, write_cb as extern "C" fn(*const u8, usize, usize, *mut c_void) -> usize);
            (api.setopt)(c, CURLOPT_WRITEDATA, &mut sink as *mut Sink as *mut c_void);
            if let Some(ca) = &ca {
                (api.setopt)(c, CURLOPT_CAINFO, ca.as_ptr());
            }

                VERIFY_TIME.store(time(std::ptr::null_mut()) as i64 + off, Ordering::Relaxed);
                (api.setopt)(c, CURLOPT_SSL_CTX_FUNCTION, ssl_ctx_cb as extern "C" fn(*mut c_void, *mut c_void, *mut c_void) -> c_int);
            }
            let rc = (api.perform)(c);
            let mut code: c_long = 0;
            (api.getinfo)(c, CURLINFO_RESPONSE_CODE, &mut code as *mut c_long);
            (api.cleanup)(c);

            }
            if code != 200 {
                bail!("{url}: HTTP {code}");
            }
            Ok(sink.buf)
        }
```

```bash
# Google Trust Services / Cloudflare, Amazon), taken from the macOS system root store.
set -euo pipefail

import re, subprocess, sys
want = ["ISRG Root X1", "ISRG Root X2", "DigiCert Global Root G2", "DigiCert Global Root CA",
        "DigiCert High Assurance EV Root CA", "USERTrust RSA Certification Authority",

found = {}
for p in pems:
    subj = subprocess.run(["openssl", "x509", "-noout", "-subject", "-nameopt", "multiline"], input=p, capture_output=True, text=True).stdout
    m = re.search(r"commonName\s*=\s*(.+)", subj)

missing = [w for w in want if w not in found]

with open(sys.argv[1], "w") as f:
    f.write("# mibpkg CA bundle - generated by scripts/make-ca.sh; do not edit\n")
    for w in want:
        f.write(f"# {w}\n{found[w]}\n")
EOF
```

```rust
//! Online collections: sources -> index.json over HTTPS, cached per collection id in
//! state/online/<id>.json (rewritten only when changed), loaded next to SD collections.
use crate::ctx::Ctx;
use crate::fetch::{Fetcher, MAX_INDEX};
use crate::fsutil::atomic_write;
use crate::index::{Collection, Index};
use crate::install::updates_available;
use crate::paths::Layout;
use crate::state::State;
use anyhow::{bail, Context, Result};
use serde::{Deserialize, Serialize};
use std::fs;
use std::path::PathBuf;

pub const DEFAULT_SOURCE: &str = "github:complex256/mibpkg-packages";

pub fn index_url(source: &str) -> Result<String> {
    if let Some(repo) = source.strip_prefix("github:") {
        let parts: Vec<&str> = repo.split('/').collect();
        let ok = |s: &str| !s.is_empty() && s.bytes().all(|b| b.is_ascii_alphanumeric() || b"-_.".contains(&b));
        if parts.len() != 2 || !parts.iter().all(|p| ok(p)) {
            bail!("source {source:?}: expected github:<owner>/<repo>");
        }
        return Ok(format!("https://github.com/{}/{}/releases/latest/download/index.json", parts[0], parts[1]));
    }
    if source.starts_with("https://") && source.ends_with(".json") {
        return Ok(source.to_string());
    }
    bail!("source {source:?}: expected github:<owner>/<repo> or an https://…/index.json URL")
}

/// The directory of an index URL (package paths resolve against it).
pub fn base_of(url: &str) -> String {
    match url.rfind('/') {
        Some(i) => url[..=i].to_string(),
        None => url.to_string(),
    }
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Cached {
    pub source: String,
    pub base_url: String,
    pub index: Index,
}

pub fn cache_path(layout: &Layout, id: &str) -> PathBuf {
    layout.state_dir().join("online").join(format!("{id}.json"))
}

/// Cached online collections (unreadable cache files are skipped).
pub fn collections(layout: &Layout) -> Vec<Collection> {
    let mut out = Vec::new();
    if let Ok(rd) = fs::read_dir(layout.state_dir().join("online")) {
        let mut paths: Vec<PathBuf> = rd.filter_map(|e| e.ok().map(|e| e.path())).filter(|p| p.extension().map_or(false, |x| x == "json")).collect();
        paths.sort();
        for p in paths {
            if let Some(c) = fs::read_to_string(&p).ok().and_then(|t| serde_json::from_str::<Cached>(&t).ok()).and_then(|c| Collection::from_online(c.index, &c.base_url).ok()) {
                out.push(c);
            }
        }
    }
    out
}

#[derive(Debug, Default)]
pub struct Report {
    pub checked: usize,
    pub errors: Vec<String>,
    pub updates: Vec<(String, String)>,
}

impl Report {
    pub fn summary(&self, now_secs: u64) -> String {
        let when = if now_secs < 1_577_836_800 { format!("checked at {now_secs} s") } else { "checked".to_string() };
        let mut s = format!("{when}, {} update{}", self.updates.len(), if self.updates.len() == 1 { "" } else { "s" });
        if !self.errors.is_empty() {
            s.push_str(&format!("; {}", self.errors.join("; ")));
        }
        s
    }
}

fn fetch_one(ctx: &Ctx, fetcher: &dyn Fetcher, source: &str) -> Result<()> {
    let url = index_url(source)?;
    let bytes = fetcher.get(&url, MAX_INDEX)?;
    let index: Index = serde_json::from_slice(&bytes).with_context(|| format!("{url}: not a valid index.json"))?;
    let base = base_of(&url);
    let coll = Collection::from_online(index, &base).with_context(|| url.clone())?;
    let cached = Cached { source: source.to_string(), base_url: base, index: coll.index.clone() };
    let mut text = serde_json::to_string_pretty(&cached)?;
    text.push('\n');
    let path = cache_path(&ctx.layout, coll.id());
    if fs::read_to_string(&path).ok().as_deref() != Some(text.as_str()) {
        let _rw = ctx.mounts.rw("/mnt/app")?;
        atomic_write(&path, text.as_bytes())?;
    }
    Ok(())
}

/// Fetch every configured source; failures are reported and leave the previous cache in place.
pub fn check(ctx: &Ctx, fetcher: &dyn Fetcher) -> Report {
    let mut r = Report::default();
    for source in &ctx.layout.settings.online_sources {
        match fetch_one(ctx, fetcher, source) {
            Ok(()) => r.checked += 1,
            Err(e) => r.errors.push(format!("{source}: {e:#}")),
        }
    }
    if let Ok(state) = State::load(&ctx.layout) {
        let mut colls = crate::media::loaded(&crate::media::scan(&ctx.layout));
        colls.extend(collections(&ctx.layout));
        r.updates = updates_available(&state, &colls, &ctx.unit);
    }
```

```rust
/// When to spawn `mibpkg online-check`: first once `internet` holds, then every `every`,
/// never while the previous check is still running.
pub struct OnlineSchedule {
    every: Duration,
    next: Option<Instant>,
    child: Option<Child>,
    spawns: u32,
}

impl OnlineSchedule {
    pub fn new(every: Duration) -> OnlineSchedule {
        OnlineSchedule { every, next: None, child: None, spawns: 0 }
    }

    pub fn spawns(&self) -> u32 {
        self.spawns
    }

    pub fn tick(&mut self, now: Instant, internet: bool, spawn: &mut dyn FnMut() -> std::io::Result<Child>) {
        if let Some(c) = self.child.as_mut() {
            match c.try_wait() {
                Ok(None) => return,
                _ => self.child = None,
            }
        }
        if !internet || self.next.map_or(false, |t| now < t) {
            return;
        }
        match spawn() {
            Ok(c) => {
                self.child = Some(c);
                self.spawns += 1;
                self.next = Some(now + self.every);
            }
            Err(e) => {
                eprintln!("mibpkg: starting online-check: {e}");
                self.next = Some(now + Duration::from_secs(300));
            }
        }
    }
}
```
