# mibpkg v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Rust package manager + supervisor for MIB2 High head units that M.I.B. users bootstrap once from an SD card and then drive entirely from generated GEM screens, with carmqtt as the first package.

**Architecture:** One std-only Rust binary (`mibpkg`) is CLI, supervisor and GEM-screen generator; three tiny pdksh shims (`launch.sh`, `gem.sh`, `custom.sh`) glue it to boot, GEM and M.I.B. Every filesystem path goes through a `Layout` rooted at a configurable directory, so the whole engine and the supervisor are tested on the host against temp dirs; all unit side effects (`mount`, `ksh -n`, `kill`, `df`, scripts) go through a `Sys` trait.

**Tech Stack:** Rust 2021 (host + `armv7-unknown-nto-qnx650` via `qnx65-armv7-toolchain:8.5-rust` `build-std`), crates: `anyhow`, `flate2` (default pure-Rust miniz backend), `semver`, `serde`/`serde_json`, `sha2`, `toml 0.8`; dev: `tempfile`. Shell: QNX 6.5 pdksh subset.

**Spec:** `docs/superpowers/specs/2026-09-26-mibpkg-design.md` (backlog: `docs/ideas.md`)

## Global Constraints

- Target: QNX 6.5.0 armle, cross-built with `docker run --rm -v "$ROOT":/src/mibpkg -w /src qnx65-armv7-toolchain:8.5-rust build-std /src/mibpkg`; output `target/armv7-unknown-nto-qnx650/release/mibpkg`. Needs Docker Desktop Rosetta enabled.
- Dependencies must be pure Rust and std-only: no `libc`, `nix`, `signal-hook`, `filetime`, `tar` crate, `clap`. (Tier-3 target; carmqtt proved only `serde`/`serde_json`/`toml`.) Task 1 proves every chosen crate cross-compiles before anything else is built.
- Do not use Rust APIs newer than the toolchain image's `rustc` (Task 1 records the version in `docs/unit-facts.md`); in particular prefer `map_or(false, ..)` over `is_some_and`.
- Persistent storage cannot exec binaries: everything executed is first copied to `/tmp`. `/tmp` is `/dev/shmem`: **no subdirectories**; runtime files are flat `/tmp/mibpkg.*` names.
- `/mnt/app` and `/mnt/system` are read-only; write only inside a `Mounts::rw` guard, which always remounts read-only (refcounted, never nested remounts).
- Shell scripts: pdksh-portable; the unit has no `dirname`, `tail`, `nohup`, `date`, `stat`. Validate every edited `startup.sh` with `ksh -n` before it replaces the original.
- GEM text is ASCII only; `"` in labels becomes `'`.
- Package/service/collection names: `[a-z0-9-]{1,40}`. Versions: semver.
- Release profile: `panic = "abort"`, `opt-level = "s"`, `lto = true` (as carmqtt).
- Repo authorship: git `complex256 <me@complex256.dev>` (already configured in this repo). Never reference the owner's real name anywhere in the repo.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.

## Review Focus

1. **GEM double tap / two actions at once** — second action must report "busy" and change nothing (test in Task 6, lock).
2. **Card pulled or file truncated mid-install** — a truncated/corrupt `.mpk` must fail before anything is written and leave the installed version active (test in Task 11).
3. **Power loss during an install** — leftover `<version>.new` dirs are cleaned by the next action and `current` still names the old version (test in Task 11).
4. **Update while the service is running** — boot.d entries are version-independent, so a reload must still restart a service whose package `current` changed (test in Task 14).
5. **Config supplied after install** — a service in `needs-config` must start by itself once Rescan imports the file (test in Task 14, recheck; Task 16, rescan).

```rust
//! Every path mibpkg touches, as seen on the unit, mapped under a root so the
//! whole engine runs against a temp dir in tests (root "/" on the unit).
use anyhow::{Context, Result};
use serde::Deserialize;
use std::path::{Path, PathBuf};

pub const HOME: &str = "/mnt/app/root/mibpkg";

#[derive(Debug, Clone, Deserialize)]
#[serde(deny_unknown_fields, default)]
pub struct Settings {
    /// Package store. v1 keeps it on /mnt/app; a setting so SD storage can come later.
    pub pkgs_dir: String,
    /// Where SD cards / USB sticks are mounted, checked in order.
    pub media_roots: Vec<String>,
    /// GEM parent screen for the mibpkg entry.
    pub gem_parent: String,
    /// Overrides unit detection (e.g. "MHI2Q").
    pub unit: Option<String>,
}

impl Default for Settings {
    fn default() -> Self {
        Settings {
            pkgs_dir: format!("{HOME}/pkgs"),
            media_roots: ["/fs/sda0", "/fs/sdb0", "/fs/sd0", "/fs/sd1", "/fs/usb0"]
                .iter()
                .map(|s| s.to_string())
                .collect(),
            gem_parent: "Main".into(),
            unit: None,
        }
    }
}

#[derive(Debug, Clone)]
pub struct Layout {
    pub root: PathBuf,
    pub settings: Settings,
}

impl Layout {
    pub fn load(root: impl Into<PathBuf>) -> Result<Layout> {
        let mut l = Layout { root: root.into(), settings: Settings::default() };
        let f = l.home().join("settings.toml");
        if f.exists() {
            let text = std::fs::read_to_string(&f).with_context(|| format!("reading {}", f.display()))?;
            l.settings = toml::from_str(&text).with_context(|| format!("parsing {}", f.display()))?;
        }
        Ok(l)
    }

    /// Map an absolute on-unit path under the root.
    pub fn p(&self, abs: &str) -> PathBuf {
        self.root.join(abs.trim_start_matches('/'))
    }
    pub fn home(&self) -> PathBuf {
        self.p(HOME)
    }
    pub fn bin_dir(&self) -> PathBuf {
        self.home().join("bin")
    }
    pub fn boot_d(&self) -> PathBuf {
        self.home().join("boot.d")
    }
    pub fn gem_dir(&self) -> PathBuf {
        self.home().join("gem")
    }
    pub fn state_dir(&self) -> PathBuf {
        self.home().join("state")
    }
    pub fn config_dir(&self, pkg: &str) -> PathBuf {
        self.state_dir().join("config").join(pkg)
    }
    pub fn pkgs_dir(&self) -> PathBuf {
        self.p(&self.settings.pkgs_dir)
    }
    pub fn pkg_dir(&self, pkg: &str) -> PathBuf {
        self.pkgs_dir().join(pkg)
    }
    pub fn engdefs(&self) -> PathBuf {
        self.p("/mnt/app/eso/hmi/engdefs")
    }
    pub fn startup_sh(&self) -> PathBuf {
        self.p("/mnt/system/etc/boot/startup.sh")
    }
    /// Flat runtime file in /tmp (the unit's /tmp cannot hold directories).
    pub fn run(&self, name: &str) -> PathBuf {
        self.p("/tmp").join(format!("mibpkg.{name}"))
    }
    pub fn tmp_bin(&self) -> PathBuf {
        self.p("/tmp/mibpkg")
    }
    /// The on-unit absolute path of a path under this layout.
    pub fn unit_path(&self, p: &Path) -> String {
        match p.strip_prefix(&self.root) {
            Ok(rel) => format!("/{}", rel.display()),
            Err(_) => p.display().to_string(),
        }
    }
}
```

```rust
//! Crash-safe file writes: write a sibling, fsync, rename over the target.
use std::fs;
use std::io::{self, Write};
use std::os::unix::fs::PermissionsExt;
use std::path::{Path, PathBuf};

pub fn tmp_sibling(path: &Path) -> PathBuf {
    let mut s = path.as_os_str().to_owned();
    s.push(".tmp");
    PathBuf::from(s)
}

pub fn atomic_write(path: &Path, data: &[u8]) -> io::Result<()> {
    if let Some(d) = path.parent() {
        fs::create_dir_all(d)?;
    }
    let tmp = tmp_sibling(path);
    {
        let mut f = fs::File::create(&tmp)?;
        f.write_all(data)?;
        f.sync_all()?;
    }
    fs::rename(&tmp, path)
}

pub fn set_mode(path: &Path, mode: u32) -> io::Result<()> {
    fs::set_permissions(path, fs::Permissions::from_mode(mode))
}

pub fn copy_atomic(src: &Path, dst: &Path, mode: u32) -> io::Result<()> {
    if let Some(d) = dst.parent() {
        fs::create_dir_all(d)?;
    }
    let tmp = tmp_sibling(dst);
    fs::copy(src, &tmp)?;
    set_mode(&tmp, mode)?;
    fs::rename(&tmp, dst)
}
```

```rust
use anyhow::{bail, Context, Result};
use serde::{Deserialize, Serialize};

use std::path::{Component, Path, PathBuf};

/// Boot phases this mibpkg implements. Anything else "requires a newer mibpkg".
pub const KNOWN_PHASES: &[&str] = &["default"];

#[derive(Debug, Clone, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct Manifest {
    pub package: PackageMeta,
    #[serde(default)]
    pub compat: Compat,
    #[serde(default, rename = "file")]
    pub files: Vec<FileEntry>,
    #[serde(default, rename = "config")]
    pub configs: Vec<ConfigEntry>,
    #[serde(default, rename = "service")]

    #[serde(default)]
    pub patch: Option<toml::Value>,
}

#[derive(Debug, Clone, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct PackageMeta {
    pub name: String,
    pub version: String,

    pub description: String,
}

#[derive(Debug, Clone, Default, PartialEq, Serialize, Deserialize)]

impl Manifest {
    pub fn parse(text: &str) -> Result<Manifest> {
        let m: Manifest = toml::from_str(text).context("invalid manifest.toml")?;
        m.validate()?;
        Ok(m)
    }

    pub fn version(&self) -> Result<semver::Version> {
        semver::Version::parse(&self.package.version)
            .with_context(|| format!("version {:?} is not semver (like 1.2.0)", self.package.version))
    }

    pub fn uses_scripts(&self) -> bool {
        self.scripts.post_install.is_some() || self.scripts.pre_remove.is_some()
    }

    fn validate(&self) -> Result<()> {
        if self.patch.is_some() {
            bail!("package uses [[patch]], which requires a newer mibpkg");
        }
        if !valid_name(&self.package.name) {
            bail!("package name {:?} must be 1-40 of [a-z0-9-]", self.package.name);
        }
        self.version()?;
        for f in &self.files {
            safe_rel(&f.src)?;
            parse_mode(&f.mode)?;
        }
        for c in &self.configs {
            safe_rel(&c.path)?;
            if let Some(e) = &c.example {
                safe_rel(e)?;
            }
        }
        let mut seen = HashSet::new();
        for s in &self.services {
            if !valid_name(&s.name) {
                bail!("service name {:?} must be 1-40 of [a-z0-9-]", s.name);
            }
            if !seen.insert(s.name.as_str()) {
                bail!("service {} is declared twice", s.name);
            }
            if !KNOWN_PHASES.contains(&s.phase.as_str()) {
                bail!("service {} uses boot phase {:?}, which requires a newer mibpkg", s.name, s.phase);
            }
            let rel = s
                .exec
                .strip_prefix("@pkg/")
                .with_context(|| format!("service {}: exec must start with @pkg/", s.name))?;
            safe_rel(rel)?;
            if !self.files.iter().any(|f| f.src == rel) {
                bail!("service {}: exec {} is not listed in [[file]]", s.name, s.exec);
            }
        }
        for s in [&self.scripts.post_install, &self.scripts.pre_remove].into_iter().flatten() {
            safe_rel(s)?;
        }
        Ok(())
    }
}

pub fn valid_name(s: &str) -> bool {
    !s.is_empty() && s.len() <= 40 && s.bytes().all(|b| b.is_ascii_lowercase() || b.is_ascii_digit() || b == b'-')
}

pub fn parse_mode(s: &str) -> Result<u32> {
    u32::from_str_radix(s, 8)
        .ok()
        .filter(|m| *m <= 0o777)
        .with_context(|| format!("invalid file mode {s:?} (octal, like \"755\")"))
}

/// A relative path that cannot escape its base directory.
pub fn safe_rel(p: &str) -> Result<PathBuf> {
    if p.is_empty() {
        bail!("empty path");
    }
    let path = Path::new(p);
    for c in path.components() {
        if !matches!(c, Component::Normal(_)) {
            bail!("unsafe path {p:?}: must be relative, without . or ..");
        }
    }
    Ok(path.to_path_buf())
}

/// Replace the @pkg / @config placeholders.
pub fn resolve(s: &str, pkg_dir: &str, config_dir: &str) -> String {
    s.replace("@pkg", pkg_dir).replace("@config", config_dir)
}
```

```rust
//! .mpk = gzip'd ustar holding manifest.toml + payload. Hand-rolled (regular
//! files and directories only) so no platform crates are needed on QNX 6.5.
use crate::manifest::{safe_rel, Manifest};
use anyhow::{bail, Context, Result};
use flate2::{read::GzDecoder, write::GzEncoder, Compression};
use sha2::{Digest, Sha256};
use std::fs;
use std::io::{Read, Write};
use std::os::unix::fs::PermissionsExt;
use std::path::{Path, PathBuf};

const BLOCK: usize = 512;

struct Entry {
    path: PathBuf,
    mode: u32,
    dir: bool,
    data: Vec<u8>,
}

pub struct Package {
    pub manifest: Manifest,
    entries: Vec<Entry>,
}

/// Build `out` from `src_dir` (which must hold manifest.toml). Dotfiles are skipped.
pub fn pack(src_dir: &Path, out: &Path) -> Result<Manifest> {
    let text = fs::read_to_string(src_dir.join("manifest.toml"))
        .with_context(|| format!("reading {}/manifest.toml", src_dir.display()))?;
    let m = Manifest::parse(&text)?;
    let mut needed: Vec<&str> = m.files.iter().map(|f| f.src.as_str()).collect();
    needed.extend(m.configs.iter().filter_map(|c| c.example.as_deref()));
    needed.extend([&m.scripts.post_install, &m.scripts.pre_remove].into_iter().flatten().map(|s| s.as_str()));
    for n in needed {
        if !src_dir.join(n).is_file() {
            bail!("{n} is named in manifest.toml but missing from {}", src_dir.display());
        }
    }
    let mut rels = Vec::new();
    collect(src_dir, Path::new(""), &mut rels)?;
    rels.sort();
    let mut gz = GzEncoder::new(
        fs::File::create(out).with_context(|| format!("creating {}", out.display()))?,
        Compression::best(),
    );
    for rel in &rels {
        let full = src_dir.join(rel);
        let meta = fs::metadata(&full)?;
        let name = rel.to_str().context("non-UTF-8 path")?;
        let mode = meta.permissions().mode() & 0o777;
        if meta.is_dir() {
            write_header(&mut gz, &format!("{name}/"), mode, 0, b'5')?;
        } else {
            let data = fs::read(&full)?;
            write_header(&mut gz, name, mode, data.len() as u64, b'0')?;
            gz.write_all(&data)?;
            pad(&mut gz, data.len())?;
        }
    }
    gz.write_all(&[0u8; BLOCK * 2])?;
    gz.finish()?;
    Ok(m)
}

fn collect(base: &Path, rel: &Path, out: &mut Vec<PathBuf>) -> Result<()> {
    for e in fs::read_dir(base.join(rel))? {
        let e = e?;
        if e.file_name().to_string_lossy().starts_with('.') {
            continue;
        }
        let r = rel.join(e.file_name());
        let ft = e.file_type()?;
        if ft.is_symlink() {
            bail!("symlinks are not allowed in packages: {}", r.display());
        }
        out.push(r.clone());
        if ft.is_dir() {
            collect(base, &r, out)?;
        }
    }
    Ok(())
}

fn write_header(w: &mut impl Write, name: &str, mode: u32, size: u64, kind: u8) -> Result<()> {
    if name.len() > 100 {
        bail!("path too long for a package (max 100 bytes): {name}");
    }
    let mut h = [0u8; BLOCK];
    h[..name.len()].copy_from_slice(name.as_bytes());
    octal(&mut h[100..108], mode as u64);
    octal(&mut h[108..116], 0);
    octal(&mut h[116..124], 0);
    octal(&mut h[124..136], size);
    octal(&mut h[136..148], 0);
    h[156] = kind;
    h[257..263].copy_from_slice(b"ustar\0");
    h[263..265].copy_from_slice(b"00");
    h[148..156].copy_from_slice(b"        ");
    let sum: u32 = h.iter().map(|b| *b as u32).sum();
    h[148..156].copy_from_slice(format!("{sum:06o}\0 ").as_bytes());
    w.write_all(&h)?;
    Ok(())
}

fn octal(field: &mut [u8], v: u64) {
    let n = field.len() - 1;
    let s = format!("{:0width$o}", v, width = n);
    field[..n].copy_from_slice(s.as_bytes());
    field[n] = 0;
}

fn pad(w: &mut impl Write, len: usize) -> Result<()> {
    let r = len % BLOCK;
    if r != 0 {
        w.write_all(&vec![0u8; BLOCK - r])?;
    }
    Ok(())
}

fn parse_octal(f: &[u8]) -> Result<u64> {
    let s = std::str::from_utf8(f)?.trim_matches(|c| c == '\0' || c == ' ');
    if s.is_empty() {
        return Ok(0);
    }
    u64::from_str_radix(s, 8).with_context(|| format!("bad octal field {s:?}"))
}

fn cstr(f: &[u8]) -> Result<String> {
    let end = f.iter().position(|b| *b == 0).unwrap_or(f.len());
    Ok(std::str::from_utf8(&f[..end])?.to_string())
}

fn read_entries(mpk: &Path) -> Result<Vec<Entry>> {
    let file = fs::File::open(mpk).with_context(|| format!("opening {}", mpk.display()))?;
    let mut r = GzDecoder::new(file);
    let mut out = Vec::new();
    let mut h = [0u8; BLOCK];
    loop {
        r.read_exact(&mut h).context("truncated package")?;
        if h.iter().all(|b| *b == 0) {
            break;
        }
        let stored = parse_octal(&h[148..156])? as u32;
        let mut hc = h;
        hc[148..156].copy_from_slice(b"        ");
        if hc.iter().map(|b| *b as u32).sum::<u32>() != stored {
            bail!("corrupt package header");
        }
        let name = cstr(&h[0..100])?;
        let prefix = cstr(&h[345..500])?;
        let full = if prefix.is_empty() { name } else { format!("{prefix}/{name}") };
        let path = safe_rel(full.trim_end_matches('/'))?;
        let mode = (parse_octal(&h[100..108])? as u32) & 0o777;
        let size = parse_octal(&h[124..136])? as usize;
        match h[156] {
            b'0' | 0 => {
                let mut data = vec![0u8; size];
                r.read_exact(&mut data).context("truncated package")?;
                let rem = size % BLOCK;
                if rem != 0 {
                    let mut p = vec![0u8; BLOCK - rem];
                    r.read_exact(&mut p).context("truncated package")?;
                }
                out.push(Entry { path, mode, dir: false, data });
            }
            b'5' => out.push(Entry { path, mode, dir: true, data: Vec::new() }),
            k => bail!("unsupported entry type {:?} for {full} (only files and directories)", k as char),
        }
    }
    Ok(out)
}

impl Package {
    pub fn read(mpk: &Path) -> Result<Package> {
        let entries = read_entries(mpk)?;
        let m = entries
            .iter()
            .find(|e| !e.dir && e.path == Path::new("manifest.toml"))
            .context("package has no manifest.toml")?;
        let manifest = Manifest::parse(std::str::from_utf8(&m.data).context("manifest.toml is not UTF-8")?)?;
        for f in &manifest.files {
            if !entries.iter().any(|e| !e.dir && e.path == Path::new(&f.src)) {
                bail!("package is missing {} named in its manifest", f.src);
            }
        }
        Ok(Package { manifest, entries })
    }

    pub fn unpacked_size(&self) -> u64 {
        self.entries.iter().map(|e| e.data.len() as u64).sum()
    }

    pub fn extract_to(&self, dest: &Path) -> Result<()> {
        if dest.exists() {
            bail!("{} already exists", dest.display());
        }
        fs::create_dir_all(dest)?;
        for e in &self.entries {
            let p = dest.join(&e.path);
            if e.dir {
                fs::create_dir_all(&p)?;
                fs::set_permissions(&p, fs::Permissions::from_mode(e.mode | 0o700))?;
            } else {
                if let Some(d) = p.parent() {
                    fs::create_dir_all(d)?;
                }
                fs::write(&p, &e.data)?;
                fs::set_permissions(&p, fs::Permissions::from_mode(e.mode))?;
            }
        }
        // Manifest modes win over archive modes for listed files.
        for f in &self.manifest.files {
            let mode = crate::manifest::parse_mode(&f.mode)?;
            fs::set_permissions(dest.join(&f.src), fs::Permissions::from_mode(mode))?;
        }
        Ok(())
    }
}

pub fn sha256_file(path: &Path) -> Result<(String, u64)> {
    let mut f = fs::File::open(path).with_context(|| format!("opening {}", path.display()))?;
    let mut h = Sha256::new();
    let mut buf = vec![0u8; 64 * 1024];
    let mut n = 0u64;
    loop {
        let k = f.read(&mut buf)?;
        if k == 0 {
            break;
        }
        h.update(&buf[..k]);
        n += k as u64;
    }
    Ok((h.finalize().iter().map(|b| format!("{b:02x}")).collect(), n))
}
```

```rust
use crate::archive::{sha256_file, Package};

use crate::manifest::{safe_rel, valid_name, Compat};

use std::fs;
use std::path::{Path, PathBuf};

pub const FORMAT: u32 = 1;

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Index {
    pub format: u32,
    pub collection: CollectionMeta,
    pub packages: Vec<IndexEntry>,
    /// Reserved for signature verification (after online updates); ignored in v1.
    #[serde(default)]
    pub signatures: Vec<serde_json::Value>,
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct CollectionMeta {
    pub id: String,
    pub name: String,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct IndexEntry {
    pub name: String,
    pub version: String,
    pub file: String,
    pub sha256: String,
    pub size: u64,
    #[serde(default)]
    pub description: String,
    #[serde(default)]
    pub compat: Compat,
    #[serde(default)]
    pub uses_scripts: bool,
}

#[derive(Debug, Clone)]
pub struct Collection {
    pub dir: PathBuf,
    pub index: Index,
}

impl Collection {
    pub fn load(dir: &Path) -> Result<Collection> {
        let p = dir.join("index.json");
        let text = fs::read_to_string(&p).with_context(|| format!("reading {}", p.display()))?;
        let index: Index = serde_json::from_str(&text).with_context(|| format!("parsing {}", p.display()))?;
        if index.format != FORMAT {
            bail!("{}: index format {} is not supported by this mibpkg", p.display(), index.format);
        }
        if !valid_name(&index.collection.id) {
            bail!("{}: collection id {:?} must be 1-40 of [a-z0-9-]", p.display(), index.collection.id);
        }
        for e in &index.packages {
            safe_rel(&e.file).with_context(|| format!("{}: package {}", p.display(), e.name))?;
        }
        Ok(Collection { dir: dir.to_path_buf(), index })
    }

    pub fn id(&self) -> &str {
        &self.index.collection.id
    }

    pub fn archive_path(&self, e: &IndexEntry) -> PathBuf {
        self.dir.join(&e.file)
    }

    /// Newest version of `name` in this collection.
    pub fn latest(&self, name: &str) -> Option<&IndexEntry> {
        self.index
            .packages
            .iter()
            .filter(|e| e.name == name)
            .max_by(|a, b| cmp_versions(&a.version, &b.version))
    }
}

pub fn cmp_versions(a: &str, b: &str) -> Ordering {
    match (semver::Version::parse(a), semver::Version::parse(b)) {
        (Ok(x), Ok(y)) => x.cmp(&y),
        _ => a.cmp(b),
    }
}

/// Host tooling: index every packages/*.mpk in `dir`.
pub fn build_index(dir: &Path, id: &str, name: &str) -> Result<Index> {
    if !valid_name(id) {
        bail!("collection id {id:?} must be 1-40 of [a-z0-9-]");
    }
    let mut files: Vec<PathBuf> = fs::read_dir(dir.join("packages"))
        .with_context(|| format!("reading {}/packages", dir.display()))?
        .filter_map(|e| e.ok().map(|e| e.path()))
        .filter(|p| p.extension().map_or(false, |x| x == "mpk"))
        .collect();
    files.sort();
    let mut packages = Vec::new();
    for f in files {
        let pkg = Package::read(&f).with_context(|| format!("reading {}", f.display()))?;
        let m = &pkg.manifest;
        let fname = f.file_name().unwrap().to_string_lossy().to_string();
        let want = format!("{}-{}.mpk", m.package.name, m.package.version);
        if fname != want {
            bail!("{fname} holds {} {}; it must be named {want}", m.package.name, m.package.version);
        }
        let (sha256, size) = sha256_file(&f)?;
        packages.push(IndexEntry {
            name: m.package.name.clone(),
            version: m.package.version.clone(),
            file: format!("packages/{fname}"),
            sha256,
            size,
            description: m.package.description.clone(),
            compat: m.compat.clone(),
            uses_scripts: m.uses_scripts(),
        });
    }
    Ok(Index {
        format: FORMAT,
        collection: CollectionMeta { id: id.into(), name: name.into() },
        packages,
        signatures: Vec::new(),
    })
}

pub fn write_index(dir: &Path, index: &Index) -> Result<()> {
    let mut text = serde_json::to_string_pretty(index)?;
    text.push('\n');
    atomic_write(&dir.join("index.json"), text.as_bytes())?;
    Ok(())
}
```

```rust
//! Which head unit this is, for package [compat] checks.
//! Source: first line of /mnt/app/img_ver.txt, e.g. "#DEV_MMX2QC_AU_NAR_G22_061PROD".
//! MMX2QC => MHI2Q (Qualcomm); other MMX2 => MHI2 (unverified, see docs/unit-facts.md).
use crate::manifest::Compat;
use crate::paths::Layout;

#[derive(Debug, Clone, Default, PartialEq)]
pub struct UnitInfo {
    pub unit: Option<String>,
    pub firmware: Option<String>,
}

impl UnitInfo {
    pub fn describe(&self) -> String {
        format!(
            "{} ({})",
            self.unit.as_deref().unwrap_or("unknown"),
            self.firmware.as_deref().unwrap_or("unknown firmware")
        )
    }
}

pub fn parse_img_ver(text: &str) -> UnitInfo {
    let first = text.lines().next().unwrap_or("").trim().trim_start_matches('#').trim().to_string();
    if first.is_empty() {
        return UnitInfo::default();
    }
    let unit = if first.contains("MMX2QC") {
        Some("MHI2Q")
    } else if first.contains("MMX2") {
        Some("MHI2")
    } else {
        None
    };
    UnitInfo { unit: unit.map(String::from), firmware: Some(first) }
}

pub fn detect(layout: &Layout) -> UnitInfo {
    let text = std::fs::read_to_string(layout.p("/mnt/app/img_ver.txt")).unwrap_or_default();
    let mut info = parse_img_ver(&text);
    if let Some(u) = &layout.settings.unit {
        info.unit = Some(u.clone());
    }
    info
}

impl Compat {
    pub fn matches(&self, u: &UnitInfo) -> bool {
        let unit_ok =
            self.units.is_empty() || u.unit.as_ref().map_or(false, |x| self.units.iter().any(|w| w == x));
        let fw_ok = self.firmware.is_empty()
            || u.firmware.as_ref().map_or(false, |x| self.firmware.iter().any(|w| x.contains(w.as_str())));
        unit_ok && fw_ok
    }
}
```

```rust
//! Every side effect on the unit that is not plain file I/O.
use anyhow::{bail, Context, Result};
use std::cell::{Cell, RefCell};
use std::path::Path;
use std::process::{Command, Stdio};
use std::time::{Duration, Instant};

pub trait Sys {
    /// `mount -uw|-ur <mount>` (sync first when going read-only).
    fn remount(&self, mount: &str, rw: bool) -> Result<()>;
    /// `ksh -n <script>` succeeded.
    fn shell_syntax_ok(&self, script: &Path) -> bool;
    /// `/bin/sh <script> <args>` with a timeout; non-zero exit is an error.
    fn run_script(&self, script: &Path, args: &[&str], env: &[(String, String)], timeout: Duration) -> Result<()>;
    fn process_alive(&self, pid: u32) -> bool;
    /// SIGTERM via `kill <pid>`.
    fn terminate(&self, pid: u32);
    /// Free bytes on the filesystem holding `path`, if `df` can tell.
    fn free_bytes(&self, path: &Path) -> Option<u64>;
}

pub struct RealSys {
    pub mounts: bool,
}

fn quiet_status(cmd: &mut Command) -> bool {
    cmd.stdin(Stdio::null())
        .stdout(Stdio::null())
        .stderr(Stdio::null())
        .status()
        .map(|s| s.success())
        .unwrap_or(false)
}

impl Sys for RealSys {
    fn remount(&self, mount: &str, rw: bool) -> Result<()> {
        if !self.mounts {
            return Ok(());
        }
        let flag = if rw { "-uw" } else { "-ur" };
        if !rw {
            let _ = Command::new("sync").status();
        }
        let st = Command::new("mount").arg(flag).arg(mount).status().context("running mount")?;
        if !st.success() {
            bail!("mount {flag} {mount} failed");
        }
        Ok(())
    }

    fn shell_syntax_ok(&self, script: &Path) -> bool {
        quiet_status(Command::new("ksh").arg("-n").arg(script))
    }

    fn run_script(&self, script: &Path, args: &[&str], env: &[(String, String)], timeout: Duration) -> Result<()> {
        let mut c = Command::new("/bin/sh");
        c.arg(script).args(args).stdin(Stdio::null());
        for (k, v) in env {
            c.env(k, v);
        }
        let mut child = c.spawn().with_context(|| format!("starting {}", script.display()))?;
        let start = Instant::now();
        loop {
            if let Some(st) = child.try_wait()? {
                if st.success() {
                    return Ok(());
                }
                bail!("{} exited with {st}", script.display());
            }
            if start.elapsed() > timeout {
                let _ = child.kill();
                let _ = child.wait();
                bail!("{} timed out after {}s", script.display(), timeout.as_secs());
            }
            std::thread::sleep(Duration::from_millis(50));
        }
    }

    fn process_alive(&self, pid: u32) -> bool {
        quiet_status(Command::new("/bin/sh").arg("-c").arg(format!("kill -0 {pid}")))
    }

    fn terminate(&self, pid: u32) {
        quiet_status(Command::new("/bin/sh").arg("-c").arg(format!("kill {pid}")));
    }

    fn free_bytes(&self, path: &Path) -> Option<u64> {
        let out = Command::new("df").arg("-k").arg(path).stderr(Stdio::null()).output().ok()?;
        let text = String::from_utf8_lossy(&out.stdout);
        let last = text.lines().last()?;
        let avail_kb: u64 = last.split_whitespace().nth(3)?.parse().ok()?;
        Some(avail_kb * 1024)
    }
}

/// Test double: records remounts, can fail them, fakes `ksh -n` and `df`;
/// processes and scripts are real (host /bin/sh).
#[derive(Default)]
pub struct RecordingSys {
    pub calls: RefCell<Vec<String>>,
    pub fail_remount_rw: Cell<bool>,
    pub syntax_bad: Cell<bool>,
    pub free: Cell<Option<u64>>,
}

const HOST: RealSys = RealSys { mounts: false };

impl Sys for RecordingSys {
    fn remount(&self, mount: &str, rw: bool) -> Result<()> {
        self.calls.borrow_mut().push(format!("{} {mount}", if rw { "rw" } else { "ro" }));
        if rw && self.fail_remount_rw.get() {
            bail!("mount -uw {mount} failed");
        }
        Ok(())
    }
    fn shell_syntax_ok(&self, _script: &Path) -> bool {
        !self.syntax_bad.get()
    }
    fn run_script(&self, script: &Path, args: &[&str], env: &[(String, String)], timeout: Duration) -> Result<()> {
        HOST.run_script(script, args, env, timeout)
    }
    fn process_alive(&self, pid: u32) -> bool {
        HOST.process_alive(pid)
    }
    fn terminate(&self, pid: u32) {
        HOST.terminate(pid)
    }
    fn free_bytes(&self, _path: &Path) -> Option<u64> {
        self.free.get()
    }
}
```

```rust
use anyhow::Result;

use std::collections::BTreeMap;

/// Refcounted `mount -uw`: nested guards remount once; the last drop goes read-only.
pub struct Mounts<'a> {
    sys: &'a dyn Sys,
    counts: RefCell<BTreeMap<String, u32>>,

    mounts: &'m Mounts<'a>,
    mount: String,
}

impl<'a> Mounts<'a> {
    pub fn new(sys: &'a dyn Sys) -> Mounts<'a> {
        Mounts { sys, counts: RefCell::new(BTreeMap::new()) }
    }

    pub fn rw<'m>(&'m self, mount: &str) -> Result<RwGuard<'m, 'a>> {
        let mut c = self.counts.borrow_mut();
        let n = c.entry(mount.to_string()).or_insert(0);
        if *n == 0 {
            self.sys.remount(mount, true)?;
        }
        *n += 1;
        Ok(RwGuard { mounts: self, mount: mount.to_string() })
    }
}

impl Drop for RwGuard<'_, '_> {
    fn drop(&mut self) {
        let mut c = self.mounts.counts.borrow_mut();
        if let Some(n) = c.get_mut(&self.mount) {
            *n -= 1;
            if *n == 0 {
                if let Err(e) = self.mounts.sys.remount(&self.mount, false) {
                    eprintln!("warning: {e:#}");
                }
            }
        }
    }
}

pub struct Ctx<'a> {
    pub layout: Layout,
    pub sys: &'a dyn Sys,
    pub mounts: Mounts<'a>,
    pub unit: UnitInfo,
}

impl<'a> Ctx<'a> {
    pub fn new(layout: Layout, sys: &'a dyn Sys) -> Ctx<'a> {
        let unit = detect(&layout);
        Ctx { layout, sys, mounts: Mounts::new(sys), unit }
    }
}
```

```rust
//! One mibpkg action at a time (GEM double taps, CLI + GEM).
use crate::paths::Layout;
use crate::sys::Sys;
use anyhow::{bail, Result};
use std::fs::{self, OpenOptions};
use std::io::{ErrorKind, Write};
use std::path::PathBuf;

pub struct Lock {
    path: PathBuf,
}

impl Lock {
    pub fn acquire(layout: &Layout, sys: &dyn Sys) -> Result<Lock> {
        let path = layout.run("lock");
        for _ in 0..2 {
            match OpenOptions::new().write(true).create_new(true).open(&path) {
                Ok(mut f) => {
                    write!(f, "{}", std::process::id())?;
                    return Ok(Lock { path });
                }
                Err(e) if e.kind() == ErrorKind::AlreadyExists => {
                    let holder = fs::read_to_string(&path).ok().and_then(|s| s.trim().parse::<u32>().ok());
                    match holder {
                        Some(pid) if sys.process_alive(pid) => {
                            bail!("busy: another mibpkg action is running (pid {pid})")
                        }
                        _ => {
                            let _ = fs::remove_file(&path);
                        }
                    }
                }
                Err(e) => return Err(e.into()),
            }
        }
        bail!("busy: could not take {}", path.display())
    }
}

impl Drop for Lock {
    fn drop(&mut self) {
        let _ = fs::remove_file(&self.path);
    }
}
```

```rust
//! Once-only backups of stock files mibpkg edits, so uninstall can restore them.
use crate::fsutil::copy_atomic;
use crate::paths::Layout;
use anyhow::{Context, Result};
use std::os::unix::fs::PermissionsExt;
use std::path::PathBuf;

pub fn backup_path(layout: &Layout, unit_abs: &str) -> PathBuf {
    layout.state_dir().join("backups").join(unit_abs.trim_start_matches('/').replace('/', "%"))
}

pub fn backup_once(layout: &Layout, unit_abs: &str) -> Result<PathBuf> {
    let dst = backup_path(layout, unit_abs);
    if !dst.exists() {
        let src = layout.p(unit_abs);
        let mode = std::fs::metadata(&src).with_context(|| format!("reading {}", src.display()))?.permissions().mode();
        copy_atomic(&src, &dst, mode & 0o7777)?;
    }
    Ok(dst)
}

pub fn restore(layout: &Layout, unit_abs: &str) -> Result<()> {
    let src = backup_path(layout, unit_abs);
    let dst = layout.p(unit_abs);
    let mode = std::fs::metadata(&src).with_context(|| format!("no backup of {unit_abs}"))?.permissions().mode();
    copy_atomic(&src, &dst, mode & 0o7777)?;
    Ok(())
}
```

```rust
//! The single startup.sh line that starts the mibpkg supervisor, and the
//! validated edit path shared with legacy-hook removal.
use crate::backups::backup_once;
use crate::ctx::Ctx;
use anyhow::{bail, Context, Result};
use std::fs;

pub const MARKER: &str = "/mnt/app/root/mibpkg/bin/launch.sh";
pub const HOOK: [&str; 2] = [
    "    ## mibpkg supervisor. Best effort: detached, no stdio, never blocks boot.\n",
    "    ( sleep 30; [ -x /mnt/app/root/mibpkg/bin/launch.sh ] && /mnt/app/root/mibpkg/bin/launch.sh ) </dev/null >/dev/null 2>&1 &\n",
];
const STARTUP_UNIT: &str = "/mnt/system/etc/boot/startup.sh";

pub fn add_hook(text: &str) -> Result<String> {
    if text.contains(MARKER) {
        return Ok(text.to_string());
    }
    let lines: Vec<&str> = text.split_inclusive('\n').collect();
    let anchor = lines
        .iter()
        .position(|l| l.trim_start().starts_with("inetd") && l.contains("/dev/null"))
        .context("startup.sh has no `inetd > /dev/null` line to anchor the mibpkg hook")?;
    let mut out = String::with_capacity(text.len() + 200);
    for (i, l) in lines.iter().enumerate() {
        out.push_str(l);
        if i == anchor {
            if !l.ends_with('\n') {
                out.push('\n');
            }
            for h in HOOK {
                out.push_str(h);
            }
        }
    }
    Ok(out)
}

/// Drop every line containing `marker`, and the `##` comment line directly above it.
pub fn remove_lines(text: &str, marker: &str) -> (String, bool) {
    let lines: Vec<&str> = text.split_inclusive('\n').collect();
    let mut drop = vec![false; lines.len()];
    for (i, l) in lines.iter().enumerate() {
        if l.contains(marker) {
            drop[i] = true;
            if i > 0 && lines[i - 1].trim_start().starts_with("##") {
                drop[i - 1] = true;
            }
        }
    }
    let changed = drop.iter().any(|d| *d);
    let out = lines.iter().zip(&drop).filter(|(_, d)| !**d).map(|(l, _)| *l).collect();
    (out, changed)
}

/// Apply `edit` to startup.sh: backup once, stage next to it (keeping its mode),
/// `ksh -n` the staged file, then rename over. Returns false if nothing changed.
pub fn edit_startup<F>(ctx: &Ctx, edit: F) -> Result<bool>
where
    F: FnOnce(&str) -> Result<Option<String>>,
{
    let path = ctx.layout.startup_sh();
    let text = fs::read_to_string(&path).with_context(|| format!("reading {}", path.display()))?;
    let new = match edit(&text)? {
        Some(n) if n != text => n,
        _ => return Ok(false),
    };
    let _sys = ctx.mounts.rw("/mnt/system")?;
    let _app = ctx.mounts.rw("/mnt/app")?;
    let pre = path.with_file_name("startup.sh.pre-mibpkg");
    if !pre.exists() {
        fs::copy(&path, &pre).context("backing up startup.sh")?;
    }
    backup_once(&ctx.layout, STARTUP_UNIT)?;
    let staged = path.with_file_name("startup.sh.mibpkg-new");
    fs::copy(&path, &staged).context("staging startup.sh")?; // carries the mode
    fs::write(&staged, &new).context("writing staged startup.sh")?;
    if !ctx.sys.shell_syntax_ok(&staged) {
        let _ = fs::remove_file(&staged);
        bail!("the edited startup.sh failed `ksh -n`; startup.sh left untouched");
    }
    fs::rename(&staged, &path).context("replacing startup.sh")?;
    Ok(true)
}

pub fn install_hook(ctx: &Ctx) -> Result<bool> {
    edit_startup(ctx, |t| add_hook(t).map(Some))
}

pub fn uninstall_hook(ctx: &Ctx) -> Result<bool> {
    edit_startup(ctx, |t| Ok(Some(remove_lines(t, MARKER).0)))
}
```

```rust
//! boot.d/<pkg>.<service>.toml: one file per service. Placeholders (@pkg,
//! @config) stay unresolved; the supervisor resolves @pkg via pkgs/<pkg>/current.
use crate::fsutil::atomic_write;
use crate::manifest::{Manifest, Restart, KNOWN_PHASES};
use crate::paths::Layout;
use anyhow::{anyhow, Context, Result};
use serde::{Deserialize, Serialize};
use std::fs;

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct BootEntry {
    pub package: String,
    pub name: String,
    pub exec: String,
    #[serde(default)]
    pub args: Vec<String>,
    pub phase: String,
    #[serde(default)]
    pub restart: Restart,
    /// Files that must exist before the service starts (required configs).
    #[serde(default)]
    pub requires: Vec<String>,
}

impl BootEntry {
    pub fn id(&self) -> String {
        format!("{}.{}", self.package, self.name)
    }
}

pub fn entries(m: &Manifest) -> Vec<BootEntry> {
    let requires: Vec<String> =
        m.configs.iter().filter(|c| c.required).map(|c| format!("@config/{}", c.path)).collect();
    m.services
        .iter()
        .map(|s| BootEntry {
            package: m.package.name.clone(),
            name: s.name.clone(),
            exec: s.exec.clone(),
            args: s.args.clone(),
            phase: s.phase.clone(),
            restart: s.restart,
            requires: requires.clone(),
        })
        .collect()
}

pub fn remove_for_package(layout: &Layout, pkg: &str) -> Result<()> {
    let dir = layout.boot_d();
    if !dir.is_dir() {
        return Ok(());
    }
    let prefix = format!("{pkg}.");
    for e in fs::read_dir(&dir)? {
        let e = e?;
        let n = e.file_name().to_string_lossy().to_string();
        if n.starts_with(&prefix) && n.ends_with(".toml") {
            fs::remove_file(e.path())?;
        }
    }
    Ok(())
}

pub fn write_for_package(layout: &Layout, pkg: &str, entries: &[BootEntry]) -> Result<()> {
    remove_for_package(layout, pkg)?;
    for e in entries {
        let p = layout.boot_d().join(format!("{}.toml", e.id()));
        atomic_write(&p, toml::to_string(e)?.as_bytes()).with_context(|| format!("writing {}", p.display()))?;
    }
    Ok(())
}

pub fn load_all(layout: &Layout) -> Vec<(String, Result<BootEntry>)> {
    let mut names: Vec<String> = match fs::read_dir(layout.boot_d()) {
        Ok(rd) => rd
            .filter_map(|e| e.ok())
            .map(|e| e.file_name().to_string_lossy().to_string())
            .filter(|n| n.ends_with(".toml"))
            .collect(),
        Err(_) => Vec::new(),
    };
    names.sort();
    names
        .into_iter()
        .map(|n| {
            let r = fs::read_to_string(layout.boot_d().join(&n))
                .map_err(anyhow::Error::from)
                .and_then(|t| toml::from_str::<BootEntry>(&t).map_err(anyhow::Error::from))
                .and_then(|e| {
                    if KNOWN_PHASES.contains(&e.phase.as_str()) {
                        Ok(e)
                    } else {
                        Err(anyhow!("boot phase {:?} requires a newer mibpkg", e.phase))
                    }
                });
            (n, r)
        })
        .collect()
}
```

```rust
/// Copy `src` into the package's config dir if its content differs. Returns true if copied.
pub fn import_file(layout: &Layout, pkg: &str, rel: &str, src: &Path) -> Result<bool> {
    let dst = layout.config_dir(pkg).join(rel);
    let new = fs::read(src)?;
    if fs::read(&dst).ok().as_deref() == Some(new.as_slice()) {
        return Ok(false);
    }
    if dst.exists() {
        let mut prev = dst.as_os_str().to_owned();
        prev.push(".prev");
        fs::copy(&dst, PathBuf::from(prev))?;
    }
    copy_atomic(src, &dst, 0o600)?;
    Ok(true)
}
```

```rust
    let mut out = Vec::new();

            Ok(rd) => rd.filter_map(|e| e.ok()).map(|e| e.path()).filter(|p| p.is_dir()).collect(),
            Err(_) => continue,
        };
        dirs.sort();
        for d in dirs {
            let c = Collection::load(&d);
            out.push((d, c));
        }
    }
    out
}

pub fn loaded(scan: &[(PathBuf, Result<Collection>)]) -> Vec<Collection> {
    let mut out: Vec<Collection> = Vec::new();
    for (_, c) in scan {
        if let Ok(c) = c {
            if !out.iter().any(|o| o.id() == c.id()) {
                out.push(c.clone());
            }
        }
    }
    out
}
```

```rust
    fs::remove_file(path).is_ok()
}

    let dir = layout.p("/tmp");
    let mut ids = Vec::new();
    if let Ok(rd) = fs::read_dir(&dir) {

                if !id.ends_with(".tmp") && take(&e.path()) {
                    ids.push(id.to_string());
                }
            }
        }
    }
    ids.sort();
    ids
}
```

```rust
//! rewriting pkgs/<name>/current; everything before it is undone on failure.

pub fn current_version(layout: &Layout, pkg: &str) -> Option<String> {

        .ok()
        .map(|s| s.trim().to_string())

}

/// Remove `<version>.new` dirs left by an interrupted install. Caller holds /mnt/app rw.
pub fn cleanup_stale(layout: &Layout) -> Result<()> {
    let dir = layout.pkgs_dir();
    if !dir.is_dir() {
        return Ok(());
    }
    for p in fs::read_dir(&dir)? {
        let p = p?.path();
        if !p.is_dir() {
            continue;
        }
        for v in fs::read_dir(&p)? {
            let v = v?.path();
            if v.is_dir() && v.extension().map_or(false, |e| e == "new") {
                fs::remove_dir_all(&v)?;
            }
        }
    }
    Ok(())
}

pub fn pick_collection<'c>(
    state: &State,
    colls: &'c [Collection],
    name: &str,
    id: Option<&str>,
) -> Result<&'c Collection> {
    let want = id.map(String::from).or_else(|| state.packages.get(name).map(|i| i.collection.clone()));
    if let Some(want) = want {
        return colls
            .iter()
            .find(|c| c.id() == want)
            .with_context(|| format!("collection {want} is not on any card"));
    }
    let having: Vec<&Collection> = colls.iter().filter(|c| c.latest(name).is_some()).collect();
    match having.len() {
        0 => bail!("{name} is not in any collection on the card"),
        1 => Ok(having[0]),
        _ => bail!(
            "{name} is in several collections ({}); choose one",
            having.iter().map(|c| c.id()).collect::<Vec<_>>().join(", ")
        ),
    }
}

fn script_env(layout: &Layout, name: &str, dir: &Path, version: &str) -> Vec<(String, String)> {
    vec![
        ("MIBPKG_PKG_DIR".into(), dir.display().to_string()),
        ("MIBPKG_CONFIG_DIR".into(), layout.config_dir(name).display().to_string()),
        ("MIBPKG_VERSION".into(), version.to_string()),
    ]
}

fn prune_versions(pkg_dir: &Path, keep: &str, keep_prev: Option<&str>) -> Result<()> {
    for e in fs::read_dir(pkg_dir)? {
        let p = e?.path();
        if !p.is_dir() {
            continue;
        }
        let n = p.file_name().unwrap().to_string_lossy().to_string();
        if n != keep && Some(n.as_str()) != keep_prev {
            fs::remove_dir_all(&p)?;
        }
    }
    Ok(())
}

fn self_update(layout: &Layout, ver_dir: &Path) -> Result<()> {
    for f in ["mibpkg", "launch.sh", "gem.sh"] {
        copy_atomic(&ver_dir.join("bin").join(f), &layout.bin_dir().join(f), 0o755)
            .with_context(|| format!("installing new {f}"))?;
    }
    control::request_selfupdate(layout)
}

pub fn install(ctx: &Ctx, media: &[PathBuf], coll: &Collection, name: &str) -> Result<String> {
    let layout = &ctx.layout;
    let coll_id = coll.id().to_string();
    let entry = coll.latest(name).with_context(|| format!("{name} is not in collection {coll_id}"))?.clone();
    if !entry.compat.matches(&ctx.unit) {
        bail!("{name} {} is not compatible with this unit: {}", entry.version, ctx.unit.describe());
    }
    let mut state = State::load(layout)?;
    let previous = state.packages.get(name).cloned();
    if let Some(p) = &previous {
        if p.collection != coll_id {
            bail!("{name} is installed from collection {}; remove it before installing it from {coll_id}", p.collection);
        }
        match cmp_versions(&entry.version, &p.version) {
            Ordering::Equal => return Ok(format!("{name} {} is already installed", p.version)),
            Ordering::Less => bail!(
                "the card has {name} {}, older than the installed {} (use Roll back instead)",
                entry.version,
                p.version
            ),
            Ordering::Greater => {}
        }
    }
    let archive = coll.archive_path(&entry);
    let (sha, size) = sha256_file(&archive).with_context(|| format!("reading {}", archive.display()))?;
    if size != entry.size || sha != entry.sha256 {
        bail!("{} is corrupt (size or sha256 does not match the index); copy it to the card again", archive.display());
    }
    let pkg = Package::read(&archive).with_context(|| format!("{} is corrupt", archive.display()))?;
    if pkg.manifest.package.name != name || pkg.manifest.package.version != entry.version {
        bail!(
            "{} holds {} {}, but the index says {name} {}",
            archive.display(),
            pkg.manifest.package.name,
            pkg.manifest.package.version,
            entry.version
        );
    }
    if let Some(free) = ctx.sys.free_bytes(&layout.p("/mnt/app")) {
        let need = pkg.unpacked_size() * 2 + 1024 * 1024;
        if free < need {
            bail!("not enough space on /mnt/app: {free} bytes free, {need} needed");
        }
    }

    let _rw = ctx.mounts.rw("/mnt/app")?;
    cleanup_stale(layout)?;
    let pkg_dir = layout.pkg_dir(name);
    let ver_dir = pkg_dir.join(&entry.version);
    let new_dir = pkg_dir.join(format!("{}.new", entry.version));
    if ver_dir.exists() {
        // Newer than current, so never the active version: a leftover or the version a
        // rollback moved away from. Re-extract it fresh.
        fs::remove_dir_all(&ver_dir)?;
    }
    let staged = (|| -> Result<()> {
        pkg.extract_to(&new_dir)?;
        fs::rename(&new_dir, &ver_dir)?;
        config::import(layout, media, &pkg.manifest)?;
        if let Some(s) = &pkg.manifest.scripts.post_install {
            ctx.sys
                .run_script(&ver_dir.join(s), &[], &script_env(layout, name, &ver_dir, &entry.version), SCRIPT_TIMEOUT)
                .context("post_install script failed")?;
        }
        Ok(())
    })();
    if let Err(e) = staged {
        let _ = fs::remove_dir_all(&new_dir);
        let _ = fs::remove_dir_all(&ver_dir);
        return Err(e);
    }

    atomic_write(&pkg_dir.join("current"), entry.version.as_bytes())?; // commit point
    bootd::write_for_package(layout, name, &bootd::entries(&pkg.manifest))?;
    let old_version = previous.as_ref().map(|p| p.version.clone());
    prune_versions(&pkg_dir, &entry.version, old_version.as_deref())?;
    state.packages.insert(
        name.to_string(),
        Installed {
            collection: coll_id.clone(),
            version: entry.version.clone(),
            previous: old_version.clone(),
            services: pkg.manifest.services.iter().map(|s| format!("{name}.{}", s.name)).collect(),
            uses_scripts: pkg.manifest.uses_scripts(),
        },
    );
    state.collections.insert(coll_id, coll.index.collection.name.clone());
    state.save(layout)?;

    let mut msg = match &old_version {
        Some(v) => format!("updated {name} {v} -> {}", entry.version),
        None => format!("installed {name} {}", entry.version),
    };
    if let Some(note) = legacy::migrate(ctx, name)? {
        msg.push_str("; ");
        msg.push_str(&note);
    }
    if name == SELF {
        self_update(layout, &ver_dir)?;
        msg.push_str("; mibpkg restarts itself");
    }
    let missing = config::missing_required(layout, &pkg.manifest);
    if !missing.is_empty() {
        msg.push_str(&format!(
            "; needs config: {} (put it on the SD card in mibpkg/config/{name}/, then Rescan)",
            missing.join(", ")
        ));
    }
    control::request_reload(layout)?;
    Ok(msg)
}

/// (name, newer version) for installed packages whose collection offers something newer.
pub fn updates_available(state: &State, colls: &[Collection]) -> Vec<(String, String)> {
    let mut out = Vec::new();
    for (name, inst) in &state.packages {
        if let Some(c) = colls.iter().find(|c| c.id() == inst.collection) {
            if let Some(e) = c.latest(name) {
                if cmp_versions(&e.version, &inst.version) == Ordering::Greater {
                    out.push((name.clone(), e.version.clone()));
                }
            }
        }
    }
    out
}

pub fn update_all(ctx: &Ctx, media: &[PathBuf], colls: &[Collection]) -> Result<Vec<String>> {
    let state = State::load(&ctx.layout)?;
    let todo = updates_available(&state, colls);
    if todo.is_empty() {
        return Ok(vec!["everything is up to date".into()]);
    }
    let mut out = Vec::new();
    for (name, _) in todo {
        let coll = pick_collection(&state, colls, &name, None)?;
        out.push(match install(ctx, media, coll, &name) {
            Ok(m) => m,
            Err(e) => format!("{name}: FAILED {e:#}"),
        });
    }
    Ok(out)
}

pub fn remove(ctx: &Ctx, name: &str, purge: bool) -> Result<String> {
    if name == SELF {
        bail!("mibpkg cannot remove itself this way; use `mibpkg uninstall-self`");
    }
    let layout = &ctx.layout;
    let mut state = State::load(layout)?;
    if !state.packages.contains_key(name) {
        bail!("{name} is not installed");
    }
    let _rw = ctx.mounts.rw("/mnt/app")?;
    if let (Ok(m), Some(dir)) = (current_manifest(layout, name), current_dir(layout, name)) {
        if let Some(s) = &m.scripts.pre_remove {
            ctx.sys
                .run_script(&dir.join(s), &[], &script_env(layout, name, &dir, &m.package.version), SCRIPT_TIMEOUT)
                .context("pre_remove script failed; package left installed")?;
        }
    }
    bootd::remove_for_package(layout, name)?;
    control::request_reload(layout)?;
    match fs::remove_dir_all(layout.pkg_dir(name)) {
        Err(e) if e.kind() != ErrorKind::NotFound => return Err(e.into()),
        _ => {}
    }
    if purge {
        match fs::remove_dir_all(layout.config_dir(name)) {
            Err(e) if e.kind() != ErrorKind::NotFound => return Err(e.into()),
            _ => {}
        }
    }
    state.packages.remove(name);
    state.save(layout)?;
    Ok(format!("removed {name}{}", if purge { " and its config" } else { "" }))
}

pub fn rollback(ctx: &Ctx, name: &str) -> Result<String> {
    let layout = &ctx.layout;
    let mut state = State::load(layout)?;
    let inst = state.packages.get(name).cloned().with_context(|| format!("{name} is not installed"))?;
    let prev = inst.previous.clone().with_context(|| format!("no earlier version of {name} is kept"))?;
    let prev_dir = layout.pkg_dir(name).join(&prev);
    let m = Manifest::parse(
        &fs::read_to_string(prev_dir.join("manifest.toml"))
            .with_context(|| format!("{name} {prev} is no longer on the unit"))?,
    )?;
    let _rw = ctx.mounts.rw("/mnt/app")?;
    atomic_write(&layout.pkg_dir(name).join("current"), prev.as_bytes())?;
    bootd::write_for_package(layout, name, &bootd::entries(&m))?;
    if name == SELF {
        self_update(layout, &prev_dir)?;
    }
    let entry = state.packages.get_mut(name).unwrap();
    entry.version = prev.clone();
    entry.previous = Some(inst.version.clone());
    entry.services = m.services.iter().map(|s| format!("{name}.{}", s.name)).collect();
    entry.uses_scripts = m.uses_scripts();
    state.save(layout)?;
    control::request_reload(layout)?;
    Ok(format!("rolled back {name} {} -> {prev}", inst.version))
}
```

```rust
//! One-time migration of software that was installed by hand before mibpkg:
//! stop it, keep its config, drop its startup.sh line, move its dir aside.
use crate::config;
use crate::ctx::Ctx;
use crate::hook::{edit_startup, remove_lines};
use anyhow::Result;
use std::fs;
use std::time::Duration;

pub struct Legacy {
    pub package: &'static str,
    pub dir: &'static str,
    /// Control script inside `dir`, run as `sh <control> stop`.
    pub control: &'static str,
    /// Text identifying its startup.sh hook line.
    pub hook_marker: &'static str,
    /// (file in `dir`, config path in the package)
    pub configs: &'static [(&'static str, &'static str)],
}

pub const KNOWN: &[Legacy] = &[Legacy {
    package: "carmqtt",
    dir: "/mnt/app/root/carmqtt",
    control: "carmqtt.sh",
    hook_marker: "/mnt/app/root/carmqtt/carmqtt.sh",
    configs: &[("carmqtt.toml", "carmqtt.toml")],
}];

pub fn migrate(ctx: &Ctx, pkg: &str) -> Result<Option<String>> {
    let l = match KNOWN.iter().find(|l| l.package == pkg) {
        Some(l) => l,
        None => return Ok(None),
    };
    let dir = ctx.layout.p(l.dir);
    if !dir.is_dir() {
        return Ok(None);
    }
    let _rw = ctx.mounts.rw("/mnt/app")?;
    let control = dir.join(l.control);
    if control.is_file() {
        if let Err(e) = ctx.sys.run_script(&control, &["stop"], &[], Duration::from_secs(30)) {
            eprintln!("warning: stopping the old {pkg}: {e:#}");
        }
    }
    for (old, new) in l.configs {
        let src = dir.join(old);
        let dst = ctx.layout.config_dir(pkg).join(new);
        if src.is_file() && !dst.exists() {
            config::import_file(&ctx.layout, pkg, new, &src)?;
        }
    }
    edit_startup(ctx, |t| Ok(Some(remove_lines(t, l.hook_marker).0)))?;
    let aside = ctx.layout.p(&format!("{}.pre-mibpkg", l.dir));
    if aside.exists() {
        return Ok(Some(format!("migrated the old {pkg} install; old files left in {} ({} already exists)", l.dir, ctx.layout.unit_path(&aside))));
    }
    fs::rename(&dir, &aside)?;
    Ok(Some(format!("migrated the old {pkg} install (old files kept in {}.pre-mibpkg)", l.dir)))
}
```

```rust
use serde::{Deserialize, Serialize};
use std::collections::BTreeMap;

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "kebab-case")]
pub enum SvcState {
    Starting,
    Running,
    Backoff,
    Failed,
    Stopped,
    NeedsConfig,
    Invalid,
}

impl fmt::Display for SvcState {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        let s = match self {
            SvcState::Starting => "starting",
            SvcState::Running => "running",
            SvcState::Backoff => "backoff",
            SvcState::Failed => "failed",
            SvcState::Stopped => "stopped",
            SvcState::NeedsConfig => "needs-config",
            SvcState::Invalid => "invalid",
        };
        f.write_str(s)
    }
}

    pub state: SvcState,
    pub pid: Option<u32>,
    pub restarts: u32,
    pub last_exit: Option<String>,
    pub error: Option<String>,

    pub disabled: bool,
    #[serde(default)]
    pub services: BTreeMap<String, SvcStatus>,

}

    }
}
```

```rust
        return Ok(());

        .arg("supervise")
        .stdin(Stdio::null())
        .stdout(log.try_clone()?)
        .stderr(log)
        .spawn()?;
    Ok(())
}
```

```rust
//! The service supervisor: starts boot.d services from /tmp copies, restarts
//! them with backoff, gives up on crash loops, keeps capped logs in RAM.
use std::collections::VecDeque;
use std::fs::{self, File, OpenOptions};
use std::io::Write;
use std::path::PathBuf;
use std::time::{Duration, Instant};

#[derive(Debug, Clone)]
pub struct Timing {
    pub backoff_start: Duration,
    pub backoff_max: Duration,
    pub fail_window: Duration,
    pub fail_count: usize,
    pub poll: Duration,
    pub stop_grace: Duration,
    pub config_recheck: Duration,
    /// A service running this long gets its backoff reset.
    pub stable_after: Duration,
}

impl Default for Timing {
    fn default() -> Self {
        Timing {
            backoff_start: Duration::from_secs(1),
            backoff_max: Duration::from_secs(300),
            fail_window: Duration::from_secs(600),
            fail_count: 5,
            poll: Duration::from_secs(1),
            stop_grace: Duration::from_secs(5),
            config_recheck: Duration::from_secs(10),
            stable_after: Duration::from_secs(60),
        }
    }
}

pub fn next_backoff(t: &Timing, prev: Option<Duration>) -> Duration {
    match prev {
        None => t.backoff_start,
        Some(p) => (p * 2).min(t.backoff_max),
    }
}

#[derive(Debug, Default)]
pub struct CrashWindow {
    exits: VecDeque<Instant>,
}

impl CrashWindow {
    /// Record an exit; true when `fail_count` exits fall within `fail_window`.
    pub fn record(&mut self, now: Instant, t: &Timing) -> bool {
        self.exits.push_back(now);
        while let Some(first) = self.exits.front() {
            if now.duration_since(*first) > t.fail_window {
                self.exits.pop_front();
            } else {
                break;
            }
        }
        self.exits.len() >= t.fail_count
    }
}

/// Append-only log that rotates to `<path>.1` once it would exceed `cap` bytes.
pub struct CappedLog {
    path: PathBuf,
    cap: u64,
    file: Option<File>,
    size: u64,
}

impl CappedLog {
    pub fn open(path: PathBuf, cap: u64) -> CappedLog {
        let size = fs::metadata(&path).map(|m| m.len()).unwrap_or(0);
        let file = OpenOptions::new().create(true).append(true).open(&path).ok();
        CappedLog { path, cap, file, size }
    }

    pub fn write(&mut self, data: &[u8]) {
        if self.size + data.len() as u64 > self.cap && self.size > 0 {
            self.file = None;
            let mut rotated = self.path.as_os_str().to_owned();
            rotated.push(".1");
            let _ = fs::rename(&self.path, PathBuf::from(rotated));
            self.file = OpenOptions::new().create(true).write(true).truncate(true).open(&self.path).ok();
            self.size = 0;
        }
        if let Some(f) = self.file.as_mut() {
            if f.write_all(data).is_ok() {
                self.size += data.len() as u64;
            }
        }
    }
}
```

```rust
use crate::control;

const LOG_CAP: u64 = 256 * 1024;

struct Service {
    entry: BootEntry,
    child: Option<Child>,
    state: SvcState,
    starts: u32,
    backoff: Option<Duration>,
    next_start: Option<Instant>,
    started_at: Option<Instant>,

    error: Option<String>,
    /// Package version the running child was started from.
    version: Option<String>,
}

impl Service {
    fn new(entry: BootEntry) -> Service {
        Service {
            entry,
            child: None,
            state: SvcState::Starting,
            starts: 0,
            backoff: None,
            next_start: None,

pub struct Supervisor<'a> {
    layout: &'a Layout,
    sys: &'a dyn Sys,
    timing: Timing,
    services: BTreeMap<String, Service>,
    invalid: BTreeMap<String, String>,
}

fn pump(mut r: impl Read + Send + 'static, log: Arc<Mutex<CappedLog>>) {
    std::thread::spawn(move || {
        let mut buf = [0u8; 4096];
        loop {
            match r.read(&mut buf) {
                Ok(0) | Err(_) => break,
                Ok(n) => {
                    if let Ok(mut l) = log.lock() {
                        l.write(&buf[..n]);
                    }
                }
            }
        }
    });
}

impl<'a> Supervisor<'a> {
    pub fn new(layout: &'a Layout, sys: &'a dyn Sys, timing: Timing) -> Supervisor<'a> {
        Supervisor { layout, sys, timing, services: BTreeMap::new(), invalid: BTreeMap::new() }
    }

    /// Re-read boot.d: start new services, stop removed ones, restart changed
    /// ones and ones whose package `current` version moved.
    pub fn reload(&mut self) {
        self.invalid.clear();
        let mut seen = Vec::new();
        for (file, r) in bootd::load_all(self.layout) {
            let e = match r {
                Ok(e) => e,
                Err(err) => {
                    self.invalid.insert(file, format!("{err:#}"));
                    continue;
                }
            };
            let id = e.id();
            seen.push(id.clone());
            let cur = current_version(self.layout, &e.package);
            let keep = match self.services.get(&id) {
                Some(s) => s.entry == e && (s.child.is_none() || s.version == cur),
                None => false,
            };
            if !keep {
                if let Some(mut old) = self.services.remove(&id) {
                    self.stop(&mut old);
                }
                self.services.insert(id, Service::new(e));
            }
        }
        let gone: Vec<String> = self.services.keys().filter(|k| !seen.contains(k)).cloned().collect();
        for id in gone {
            if let Some(mut s) = self.services.remove(&id) {
                self.stop(&mut s);
            }
        }
    }

    pub fn restart(&mut self, id: &str) {
        if let Some(mut s) = self.services.remove(id) {
            self.stop(&mut s);
            let fresh = Service::new(s.entry.clone());
            self.services.insert(id.to_string(), fresh);
        }
    }

    pub fn stop_all(&mut self) {
        let ids: Vec<String> = self.services.keys().cloned().collect();
        for id in ids {
            let mut s = self.services.remove(&id).unwrap();
            self.stop(&mut s);
            self.services.insert(id, s);
        }
    }

    fn stop(&self, s: &mut Service) {
        if let Some(mut child) = s.child.take() {
            self.sys.terminate(child.id());
            let end = Instant::now() + self.timing.stop_grace;
            loop {
                match child.try_wait() {
                    Ok(Some(_)) => break,
                    Ok(None) if Instant::now() < end => std::thread::sleep(Duration::from_millis(20)),
                    _ => {
                        let _ = child.kill();
                        let _ = child.wait();
                        break;
                    }
                }
            }
        }
        s.state = SvcState::Stopped;
    }

    pub fn tick(&mut self, now: Instant) {
        let ids: Vec<String> = self.services.keys().cloned().collect();
        for id in ids {
            let mut s = self.services.remove(&id).unwrap();
            self.tick_one(&mut s, now);
            self.services.insert(id, s);
        }
    }

    fn tick_one(&self, s: &mut Service, now: Instant) {
        let t = &self.timing;
        if let Some(child) = s.child.as_mut() {
            match child.try_wait() {
                Ok(Some(st)) => {
                    s.child = None;
                    s.last_exit = Some(st.to_string());
                    let restart = match s.entry.restart {
                        Restart::Always => true,
                        Restart::OnFailure => !st.success(),
                        Restart::Never => false,
                    };
                    if !restart {
                        s.state = SvcState::Stopped;
                    } else if s.window.record(now, t) {
                        s.state = SvcState::Failed;
                    } else {
                        let b = next_backoff(t, s.backoff);
                        s.backoff = Some(b);
                        s.next_start = Some(now + b);
                        s.state = SvcState::Backoff;
                    }
                }
                Ok(None) => {
                    if s.started_at.map_or(false, |at| now.duration_since(at) >= t.stable_after) {
                        s.backoff = None;
                    }
                }
                Err(e) => s.error = Some(e.to_string()),
            }
        }
        let due = s.next_start.map_or(true, |at| now >= at);
        if s.child.is_none()
            && matches!(s.state, SvcState::Starting | SvcState::Backoff | SvcState::NeedsConfig)
            && due
        {
            self.start(s, now);
        }
    }

    fn start(&self, s: &mut Service, now: Instant) {
        let e = &s.entry;
        let pkg_dir = match current_dir(self.layout, &e.package) {
            Some(d) => d,
            None => {
                s.state = SvcState::Invalid;
                s.error = Some(format!("package {} is not installed", e.package));
                return;
            }
        };
        let pkg_s = pkg_dir.display().to_string();
        let cfg_s = self.layout.config_dir(&e.package).display().to_string();
        let res = |x: &str| resolve(x, &pkg_s, &cfg_s);
        if let Some(missing) = e.requires.iter().map(|r| res(r)).find(|p| !Path::new(p).is_file()) {
            s.state = SvcState::NeedsConfig;
            s.error = Some(format!("missing {missing}"));
            s.next_start = Some(now + self.timing.config_recheck);
            return;
        }
        let id = e.id();
        let bin = self.layout.run(&id);
        if let Err(err) = copy_atomic(Path::new(&res(&e.exec)), &bin, 0o755) {
            s.state = SvcState::Invalid;
            s.error = Some(format!("copying {} to /tmp: {err}", e.exec));
            return;
        }
        let log = Arc::new(Mutex::new(CappedLog::open(self.layout.run(&format!("{id}.log")), LOG_CAP)));
        let spawned = Command::new(&bin)
            .args(e.args.iter().map(|a| res(a)))
            .current_dir(&pkg_dir)
            .env("MIBPKG_PKG_DIR", &pkg_s)
            .env("MIBPKG_CONFIG_DIR", &cfg_s)
            .stdin(Stdio::null())
            .stdout(Stdio::piped())
            .stderr(Stdio::piped())
            .spawn();
        match spawned {
            Ok(mut child) => {
                if let Some(o) = child.stdout.take() {
                    pump(o, log.clone());
                }
                if let Some(er) = child.stderr.take() {
                    pump(er, log);
                }
                s.child = Some(child);
                s.state = SvcState::Running;
                s.starts += 1;
                s.started_at = Some(now);
                s.error = None;
                s.version = current_version(self.layout, &e.package);
            }
            Err(err) => {
                s.error = Some(format!("starting {id}: {err}"));
                if s.window.record(now, &self.timing) {
                    s.state = SvcState::Failed;
                } else {
                    let b = next_backoff(&self.timing, s.backoff);
                    s.backoff = Some(b);
                    s.next_start = Some(now + b);
                    s.state = SvcState::Backoff;
                }
            }
        }
    }

    pub fn status(&self) -> Status {
        let services = self
            .services
            .iter()
            .map(|(id, s)| {
                (
                    id.clone(),
                    SvcStatus {
                        state: s.state,
                        pid: s.child.as_ref().map(|c| c.id()),
                        restarts: s.starts.saturating_sub(1),
                        last_exit: s.last_exit.clone(),
                        error: s.error.clone(),
                    },
                )
            })
            .collect();
        Status { updated: now_secs(), pid: std::process::id(), disabled: false, services, invalid: self.invalid.clone() }
    }
}

/// Kill service pids recorded by a supervisor that died without stopping them.
fn reap_orphans(layout: &Layout, sys: &dyn Sys) {
    if let Some(prev) = status::read(layout) {
        for s in prev.services.values() {
            if let Some(pid) = s.pid {
                if sys.process_alive(pid) {
                    sys.terminate(pid);
                }
            }
        }
    }
}

/// The supervisor main loop (`mibpkg supervise`).
pub fn run(layout: &Layout, sys: &dyn Sys, timing: Timing) -> Result<()> {
    if let Some(pid) = control::supervisor_pid(layout, sys) {
        if pid != std::process::id() {
            bail!("a supervisor is already running (pid {pid})");
        }
    }
    atomic_write(&layout.run("pid"), std::process::id().to_string().as_bytes())?;
    reap_orphans(layout, sys);
    if media::disabled(layout) {
        println!("mibpkg: DISABLE marker on the card; starting nothing");
        status::write(layout, &Status { updated: now_secs(), pid: std::process::id(), disabled: true, ..Default::default() })?;
        let _ = fs::remove_file(layout.run("pid"));
        return Ok(());
    }
    let mut sup = Supervisor::new(layout, sys, timing.clone());
    sup.reload();
    loop {
        if control::take(&layout.run("stop")) {
            sup.stop_all();
            break;
        }
        if control::take(&layout.run("selfupdate")) {
            sup.stop_all();
            let _ = status::write(layout, &sup.status());
            let _ = fs::remove_file(layout.run("pid"));
            Command::new("/bin/sh")
                .arg(layout.bin_dir().join("launch.sh"))
                .stdin(Stdio::null())
                .stdout(Stdio::null())
                .stderr(Stdio::null())
                .spawn()?;
            return Ok(());
        }
        if control::take(&layout.run("reload")) {
            sup.reload();
        }
        for id in control::take_restarts(layout) {
            sup.restart(&id);
        }
        sup.tick(Instant::now());
        if let Err(e) = status::write(layout, &sup.status()) {
            eprintln!("mibpkg: writing status: {e:#}");
        }
        std::thread::sleep(timing.poll);
    }
    let _ = status::write(layout, &sup.status());
    let _ = fs::remove_file(layout.run("pid"));
    Ok(())
}
```

```rust
//! Generated GEM (green engineering menu) screens: static .esd files in
//! /eso/hmi/engdefs whose buttons run one-line scripts in <home>/gem/.
use crate::config::missing_required;
use crate::control::supervisor_pid;
use crate::ctx::Ctx;
use crate::fsutil::{atomic_write, set_mode};
use crate::index::{cmp_versions, Collection, IndexEntry};
use crate::install::{current_manifest, updates_available, SELF};
use crate::media;
use crate::paths::{Layout, HOME};
use crate::state::State;
use crate::status::{self, Status};
use crate::unit::UnitInfo;
use anyhow::Result;
use std::cmp::Ordering;
use std::collections::BTreeMap;
use std::fs;
use std::path::PathBuf;

pub enum Item {
    Text(String),
    Button { label: String, action: Vec<String> },
}

pub struct Screen {
    pub name: String,
    pub parent: String,
    pub items: Vec<Item>,
}

pub struct Model<'a> {
    pub layout: &'a Layout,
    pub unit: &'a UnitInfo,
    pub state: &'a State,
    pub status: Option<&'a Status>,
    pub scan: &'a [(PathBuf, Result<Collection>)],
    pub disabled: bool,
    pub supervisor_running: bool,
}

pub fn screen_name(pkg: &str) -> String {
    format!("mibpkg_{}", pkg.replace('-', "_"))
}

pub fn script_name(action: &[String]) -> String {
    format!("{}.sh", action.join("-"))
}

pub fn script_body(action: &[String]) -> String {
    format!("#!/bin/sh\nexec /bin/sh {HOME}/bin/gem.sh {}\n", action.join(" "))
}

fn clean(s: &str) -> String {
    s.chars()
        .map(|c| if c == '"' { '\'' } else if c.is_ascii() && !c.is_ascii_control() { c } else { '?' })
        .collect()
}

pub fn render(s: &Screen, gem_dir_unit: &str) -> String {
    let mut o = format!("screen {} {}\n", s.name, s.parent);
    for it in &s.items {
        o.push('\n');
        match it {
            Item::Text(t) => o.push_str(&format!(
                "keyValue\n\tvalue String sys 0x00000000 0\n\t\tlabel \"{}\"\n\t\tpoll 0\n",
                clean(t)
            )),
            Item::Button { label, action } => o.push_str(&format!(
                "script\n\tvalue sys 1 0x100 \"{}/{}\"\n\tlabel \"{}\"\n",
                gem_dir_unit,
                script_name(action),
                clean(label)
            )),
        }
    }
    o
}

fn text(s: impl Into<String>) -> Item {
    Item::Text(s.into())
}

fn button(label: impl Into<String>, action: &[&str]) -> Item {
    Item::Button { label: label.into(), action: action.iter().map(|s| s.to_string()).collect() }
}

pub fn screens(m: &Model) -> Vec<Screen> {
    let colls: Vec<&Collection> = m.scan.iter().filter_map(|(_, c)| c.as_ref().ok()).collect();
    let owned: Vec<Collection> = colls.iter().map(|c| (*c).clone()).collect();
    let updates = updates_available(m.state, &owned);

    let mut main = vec![
        text(format!("mibpkg {} - unit {}", env!("CARGO_PKG_VERSION"), m.unit.describe())),
        text(format!("supervisor: {}", if m.supervisor_running { "running" } else { "not running" })),
    ];
    if m.disabled {
        main.push(text("DISABLE marker on the card: no services are started"));
    }
    if m.scan.is_empty() {
        main.push(text("No collections on SD/USB (expected mibpkg/collections/<id>/index.json)"));
    }
    for (dir, c) in m.scan {
        main.push(match c {
            Ok(c) => text(format!("card: {} [{}] - {} packages", c.index.collection.name, c.id(), c.index.packages.len())),
            Err(e) => text(format!("card: unreadable collection {}: {e:#}", dir.display())),
        });
    }
    main.push(text(format!("installed: {}", m.state.packages.len())));
    main.push(button("Rescan SD card", &["rescan"]));
    if !updates.is_empty() {
        main.push(button(format!("Update all ({})", updates.len()), &["update-all"]));
    }
    if let Some(r) = m.state.results.get("_") {
        main.push(text(format!("last result: {r}")));
    }
    let mut out = vec![Screen { name: "mibpkg".into(), parent: m.layout.settings.gem_parent.clone(), items: main }];

    // name -> [(collection, newest entry)]
    let mut available: BTreeMap<String, Vec<(&Collection, &IndexEntry)>> = BTreeMap::new();
    for &c in &colls {
        let mut names: Vec<&str> = c.index.packages.iter().map(|e| e.name.as_str()).collect();
        names.sort();
        names.dedup();
        for n in names {
            available.entry(n.to_string()).or_default().push((c, c.latest(n).unwrap()));
        }
    }
    let mut names: Vec<String> = available.keys().cloned().collect();
    names.extend(m.state.packages.keys().cloned());
    names.sort();
    names.dedup();

    for name in names {
        let inst = m.state.packages.get(&name);
        let avail = available.get(&name).cloned().unwrap_or_default();
        let desc = avail.first().map(|(_, e)| e.description.clone()).unwrap_or_default();
        let mut items = vec![text(if desc.is_empty() { name.clone() } else { format!("{name}: {desc}") })];
        items.push(text(match inst {
            Some(i) => format!("installed: {}", i.version),
            None => "not installed".to_string(),
        }));
        for (c, e) in &avail {
            let mut l = format!("card [{}]: {}", c.id(), e.version);
            if !e.compat.matches(m.unit) {
                l.push_str(" (not for this unit)");
            }
            if e.uses_scripts {
                l.push_str(" (!) runs scripts");
            }
            items.push(text(l));
        }
        match inst {
            None => {
                for (c, e) in &avail {
                    if e.compat.matches(m.unit) {
                        items.push(button(format!("Install {} from {}", e.version, c.id()), &["install", name.as_str(), c.id()]));
                    }
                }
            }
            Some(i) => {
                if let Some((c, e)) = avail.iter().find(|(c, _)| c.id() == i.collection) {
                    if cmp_versions(&e.version, &i.version) == Ordering::Greater && e.compat.matches(m.unit) {
                        items.push(button(format!("Update to {}", e.version), &["install", name.as_str(), c.id()]));
                    }
                }
                if !i.services.is_empty() {
                    items.push(button("Restart", &["restart", name.as_str()]));
                }
                if let Some(p) = &i.previous {
                    items.push(button(format!("Roll back to {p}"), &["rollback", name.as_str()]));
                }
                if name != SELF {
                    items.push(button("Remove", &["remove", name.as_str()]));
                }
                for id in &i.services {
                    let line = match m.status.and_then(|s| s.services.get(id)) {
                        Some(s) => format!(
                            "{id}: {}{}{}",
                            s.state,
                            s.pid.map(|p| format!(" pid {p}")).unwrap_or_default(),
                            if s.restarts > 0 { format!(" restarts {}", s.restarts) } else { String::new() }
                        ),
                        None => format!("{id}: not started"),
                    };
                    items.push(text(line));
                }
                if let Ok(man) = current_manifest(m.layout, &name) {
                    let missing = missing_required(m.layout, &man);
                    if !missing.is_empty() {
                        items.push(text(format!(
                            "needs config: {} - put it on the card in mibpkg/config/{name}/ then Rescan",
                            missing.join(", ")
                        )));
                    }
                }
            }
        }
        if let Some(r) = m.state.results.get(&name) {
            items.push(text(format!("last result: {r}")));
        }
        out.push(Screen { name: screen_name(&name), parent: "mibpkg".into(), items });
    }
    out
}

/// Delete every mibpkg*.esd in engdefs. Caller holds /mnt/app rw.
pub fn remove_screens(layout: &Layout) -> Result<()> {
    let eng = layout.engdefs();
    if let Ok(rd) = fs::read_dir(&eng) {
        for e in rd.filter_map(|e| e.ok()) {
            let n = e.file_name().to_string_lossy().to_string();
            if n.starts_with("mibpkg") && n.ends_with(".esd") {
                fs::remove_file(e.path())?;
            }
        }
    }
    Ok(())
}

pub fn regenerate(ctx: &Ctx) -> Result<()> {
    let layout = &ctx.layout;
    let state = State::load(layout)?;
    let scan = media::scan(layout);
    let st = status::read(layout);
    let model = Model {
        layout,
        unit: &ctx.unit,
        state: &state,
        status: st.as_ref(),
        scan: &scan,
        disabled: media::disabled(layout),
        supervisor_running: supervisor_pid(layout, ctx.sys).is_some(),
    };
    let screens = screens(&model);
    let _rw = ctx.mounts.rw("/mnt/app")?;
    fs::create_dir_all(layout.engdefs())?;
    remove_screens(layout)?;
    let gd = layout.gem_dir();
    if let Ok(rd) = fs::read_dir(&gd) {
        for e in rd.filter_map(|e| e.ok()) {
            if e.file_name().to_string_lossy().ends_with(".sh") {
                fs::remove_file(e.path())?;
            }
        }
    }
    fs::create_dir_all(&gd)?;
    let gem_unit = layout.unit_path(&gd);
    for s in &screens {
        atomic_write(&layout.engdefs().join(format!("{}.esd", s.name)), render(s, &gem_unit).as_bytes())?;
        for it in &s.items {
            if let Item::Button { action, .. } = it {
                let p = gd.join(script_name(action));
                atomic_write(&p, script_body(action).as_bytes())?;
                set_mode(&p, 0o755)?;
            }
        }
    }
    Ok(())
}
```

```rust
pub fn run(args: &[String]) -> Result<i32> {
    let mut root = PathBuf::from("/");
    let mut no_supervisor = false;
    let mut rest: Vec<String> = Vec::new();
    let mut it = args.iter();
    while let Some(a) = it.next() {
        match a.as_str() {
            "--root" => root = PathBuf::from(it.next().context("--root needs a directory")?),
            "--no-supervisor" => no_supervisor = true,
            _ => rest.push(a.clone()),
        }
    }
    let cmd = match rest.first() {
        Some(c) => c.clone(),
        None => {
            eprintln!("{USAGE}");
            return Ok(2);
        }
    };
    let args = &rest[1..];
    match cmd.as_str() {
        "build" => return host_build(args),
        "index" => return host_index(args),
        "help" | "--help" | "-h" => {
            println!("{USAGE}");
            return Ok(0);
        }
        _ => {}
    }

    let layout = Layout::load(&root)?;
    let sys = RealSys { mounts: root == Path::new("/") };
    let ctx = Ctx::new(layout, &sys);
    let after = |ctx: &Ctx| {
        if let Err(e) = gem::regenerate(ctx) {
            eprintln!("warning: updating GEM screens: {e:#}");
        }
        if !no_supervisor {
            if let Err(e) = control::ensure_supervisor(&ctx.layout, ctx.sys) {
                eprintln!("warning: starting the supervisor: {e:#}");
            }
        }
    };
    match cmd.as_str() {
        "supervise" => {
            supervisor::run(&ctx.layout, &sys, Timing::default())?;
            Ok(0)
        }
        "status" => {
            print_status(&ctx);
            Ok(0)
        }
        "list" => {
            print_list(&ctx)?;
            Ok(0)
        }
        "install" | "remove" | "rollback" | "restart" | "rescan" | "update-all" => {
            let r = action(&ctx, &cmd, args);
            after(&ctx);
            println!("{}", r?);
            Ok(0)
        }
        "gem" => {
            let verb = args.first().context("gem needs an action")?.clone();
            let key = match verb.as_str() {
                "install" | "remove" | "rollback" | "restart" => args.get(1).cloned().unwrap_or_else(|| "_".into()),
                _ => "_".into(),
            };
            let text = match action(&ctx, &verb, &args[1..]) {
                Ok(m) => format!("OK: {m}"),
                Err(e) => format!("FAILED: {e:#}"),
            };
            if let Err(e) = record_result(&ctx, &key, &text) {
                eprintln!("warning: recording result: {e:#}");
            }
            after(&ctx);
            println!("{text}");
            Ok(0)
        }
        "bootstrap" => {
            let _lock = Lock::acquire(&ctx.layout, ctx.sys)?;
            {
                let _rw = ctx.mounts.rw("/mnt/app")?;
                for d in [ctx.layout.boot_d(), ctx.layout.state_dir(), ctx.layout.gem_dir(), ctx.layout.pkgs_dir()] {
                    fs::create_dir_all(&d).with_context(|| format!("creating {}", d.display()))?;
                }
            }
            let changed = hook::install_hook(&ctx)?;
            after(&ctx);
            println!("{}", if changed { "boot hook installed" } else { "boot hook already present" });
            Ok(0)
        }
        "uninstall-self" => {
            let _lock = Lock::acquire(&ctx.layout, ctx.sys)?;
            control::request_stop(&ctx.layout)?;
            let end = Instant::now() + Duration::from_secs(15);
            while control::supervisor_pid(&ctx.layout, ctx.sys).is_some() && Instant::now() < end {
                std::thread::sleep(Duration::from_millis(200));
            }
            hook::uninstall_hook(&ctx)?;
            {
                let _rw = ctx.mounts.rw("/mnt/app")?;
                gem::remove_screens(&ctx.layout)?;
            }
            let _ = fs::remove_file(ctx.layout.run("stop"));
            println!(
                "mibpkg removed from boot and GEM; installed files remain in {} (delete by hand if wanted)",
                ctx.layout.unit_path(&ctx.layout.home())
            );
            Ok(0)
        }
        other => bail!("unknown command {other:?}\n{USAGE}"),
    }
}

fn arg<'a>(args: &'a [String], i: usize, what: &str) -> Result<&'a str> {
    args.get(i).map(|s| s.as_str()).with_context(|| format!("missing {what}"))
}

fn action(ctx: &Ctx, verb: &str, args: &[String]) -> Result<String> {
    let _lock = Lock::acquire(&ctx.layout, ctx.sys)?;
    let media_roots = media::roots(&ctx.layout);
    let colls: Vec<Collection> = media::loaded(&media::scan(&ctx.layout));
    let state = State::load(&ctx.layout)?;
    match verb {
        "install" => {
            let name = arg(args, 0, "package name")?;
            let coll = install::pick_collection(&state, &colls, name, args.get(1).map(|s| s.as_str()))?;
            install::install(ctx, &media_roots, coll, name)
        }
        "remove" => install::remove(ctx, arg(args, 0, "package name")?, args.iter().any(|a| a == "--purge")),
        "rollback" => install::rollback(ctx, arg(args, 0, "package name")?),
        "restart" => {
            let name = arg(args, 0, "package name")?;
            let inst = state.packages.get(name).with_context(|| format!("{name} is not installed"))?;
            for id in &inst.services {
                control::request_restart(&ctx.layout, id)?;
            }
            Ok(format!("restart requested for {name}"))
        }
        "rescan" => {
            let _rw = ctx.mounts.rw("/mnt/app")?;
            let mut msgs = Vec::new();
            for name in state.packages.keys() {
                if let Ok(m) = install::current_manifest(&ctx.layout, name) {
                    let got = config::import(&ctx.layout, &media_roots, &m)?;
                    if !got.is_empty() {
                        msgs.push(format!("{name}: imported {}", got.join(", ")));
                    }
                }
            }
            control::request_reload(&ctx.layout)?;
            Ok(if msgs.is_empty() { "rescanned; no new config files".into() } else { msgs.join("; ") })
        }
        "update-all" => Ok(install::update_all(ctx, &media_roots, &colls)?.join("; ")),
        other => bail!("unknown action {other:?}"),
    }
}

fn record_result(ctx: &Ctx, key: &str, text: &str) -> Result<()> {
    let _rw = ctx.mounts.rw("/mnt/app")?;
    let mut st = State::load(&ctx.layout)?;
    st.results.insert(key.to_string(), format!("{text} ({})", utc_stamp(now_secs())));
    st.save(&ctx.layout)
}

fn print_status(ctx: &Ctx) {
    match status::read(&ctx.layout) {
        None => println!("supervisor: no status (not running since boot?)"),
        Some(s) => {
            let alive = control::supervisor_pid(&ctx.layout, ctx.sys).is_some();
            println!("supervisor pid {} ({}){}", s.pid, if alive { "running" } else { "gone" }, if s.disabled { ", DISABLED" } else { "" });
            for (id, v) in &s.services {
                println!(
                    "  {id}: {}{} restarts {}{}",
                    v.state,
                    v.pid.map(|p| format!(" pid {p}")).unwrap_or_default(),
                    v.restarts,
                    v.error.as_ref().map(|e| format!(" ({e})")).unwrap_or_default()
                );
            }
            for (f, e) in &s.invalid {
                println!("  boot.d/{f}: {e}");
            }
        }
    }
}

fn print_list(ctx: &Ctx) -> Result<()> {
    println!("unit: {}", ctx.unit.describe());

    for (n, i) in &st.packages {
        println!("installed {n} {} [{}]{}", i.version, i.collection, i.previous.as_ref().map(|p| format!(" (previous {p})")).unwrap_or_default());

                }

        }
    }
    Ok(())
}

fn host_index(args: &[String]) -> Result<i32> {

/// "YYYY-MM-DD HH:MM UTC" without a date crate (the unit has no `date` either).
pub fn utc_stamp(secs: u64) -> String {
    let days = (secs / 86_400) as i64;
    let rem = secs % 86_400;
    let (y, m, d) = civil_from_days(days);
    format!("{y:04}-{m:02}-{d:02} {:02}:{:02} UTC", rem / 3600, (rem % 3600) / 60)
}

fn civil_from_days(z: i64) -> (i64, u32, u32) {
    let z = z + 719_468;
    let era = (if z >= 0 { z } else { z - 146_096 }) / 146_097;
    let doe = (z - era * 146_097) as u64;
    let yoe = (doe - doe / 1460 + doe / 36_524 - doe / 146_096) / 365;
    let y = yoe as i64 + era * 400;
    let doy = doe - (365 * yoe + yoe / 4 - yoe / 100);
    let mp = (5 * doy + 2) / 153;
    let d = (doy - (153 * mp + 2) / 5 + 1) as u32;
    let m = (if mp < 10 { mp + 3 } else { mp - 9 }) as u32;
    (if m <= 2 { y + 1 } else { y }, m, d)
}
```

```sh
#!/bin/sh
# mibpkg boot entry, run from the one startup.sh hook line (detached, no stdio).
# Persistent storage cannot exec binaries, so mibpkg runs from /tmp (RAM).
# /tmp cannot hold directories: every runtime file is a flat /tmp/mibpkg.* name.
# pdksh subset only; the unit has no dirname, tail, nohup or date.
HOME_DIR=${MIBPKG_HOME:-/mnt/app/root/mibpkg}
RUN=${MIBPKG_RUN:-/tmp}
ROOTS=${MIBPKG_MEDIA:-"/fs/sda0 /fs/sdb0 /fs/sd0 /fs/sd1 /fs/usb0"}
WAIT=${MIBPKG_WAIT:-15}
LOG=$RUN/mibpkg.log

# Give the media system a moment to mount a card, so a DISABLE card is seen.
i=0
found=0
while [ $i -lt "$WAIT" ]; do
    for r in $ROOTS; do
        [ -d "$r" ] && found=1
    done
    [ $found = 1 ] && break
    sleep 1
    i=$((i + 1))
done

for r in $ROOTS; do
    if [ -f "$r/mibpkg/DISABLE" ]; then
        echo "mibpkg: $r/mibpkg/DISABLE present, starting nothing" >>"$LOG"
        exit 0
    fi
done

cp "$HOME_DIR/bin/mibpkg" "$RUN/mibpkg.new" || exit 1
chmod 755 "$RUN/mibpkg.new"
mv "$RUN/mibpkg.new" "$RUN/mibpkg" || exit 1
exec "$RUN/mibpkg" $MIBPKG_ARGS supervise >>"$LOG" 2>&1
```

````markdown
# mibpkg

Package manager for MIB2 High head units (MHI2 / MHI2Q, QNX 6.5). Install, update and remove
software from an SD card using the green engineering menu (GEM); a supervisor starts and
watches the installed services.

## For users

1. Unzip `mibpkg-sd-<version>.zip` onto the M.I.B. SD card (FAT32).
2. If a package needs a config file (e.g. carmqtt), put it on the card at
   `mibpkg/config/<package>/<file>` (an example ships in the package).
3. GEM -> M.I.B. -> Advanced Settings -> Run Custom Script. This installs mibpkg once.
4. GEM -> mibpkg: install, update, remove, restart, roll back.

Emergency stop: create an empty file `mibpkg/DISABLE` on the card and reboot; no package
services start while it is present.

## For developers

- `cargo test` — host tests (all unit paths are mapped under a temp root).
- `scripts/build.sh` — cross-build for the unit (Docker, `qnx65-armv7-toolchain:8.5-rust`).
- `mibpkg build <src-dir> <out-dir>` — build a `.mpk` from a directory with `manifest.toml`.
- `mibpkg index <collection-dir> --id ID --name NAME` — write `index.json`.
- `scripts/bundle.sh [extra.mpk ...]` — SD bundle with the official collection.

Design: `docs/superpowers/specs/2026-09-26-mibpkg-design.md`. Backlog: `docs/ideas.md`.
Verified unit facts: `docs/unit-facts.md`.
````
